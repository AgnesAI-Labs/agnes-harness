# File search

The official `grep` and `find` definitions execute pinned `@vscode/ripgrep` through the public confined executor. Every candidate file passes the public filesystem policy check. Limits produce a readable spill artifact; process capture ceilings explicitly mark partial searches. Legacy filesystem-walker definitions remain available internally for artifact grep and existing adapter fixtures. `ls` continues to use the public filesystem port.

See [default tools](../../../../docs/reference/default-tools.md). Binary and wrapper provenance is recorded in `third-party/runtime-dependencies.json`; CLI delivery builds copy the executable and upstream licenses.

# Agnes Skill Helper

Official bundled plugin. New local profiles and existing profiles adopting default helpers install, trust and enable missing shipped helpers once, offline. Already installed packages retain their version, trust and enablement state. Later starts and upgrades preserve user disable/removal choices. Removing this helper does not delete resources it previously connected.

Imports local Skill directories, public GitHub repositories/subdirectories, HTTPS raw Markdown/JSON manifests and local ZIP files. With optional official skill-creator guidance, creates instruction-only drafts through the reviewed Skill installer: SKILL.md and optional Markdown/TXT/JSON/YAML/CSV resources outside scripts/ are validated statically, without JavaScript generation or Node tests. Creation returns prepared with name, description, files, digest and revision; install commit presents exactly one confirmation to install and optionally trust/enable, even under full access. Defaults to workspace scope with enable=true; user scope and install-only remain available. The Host binds approval to frozen bytes and retains authenticated authoring provenance in the private receipt. Invalid frontmatter, collisions, unsafe paths and oversized resources are refused.

Code-bearing Skills, package manifests and unknown file types retain private plugin candidates: creation returns draft; test runs the existing Node author tests, commit submits human review, and only Settings → Plugins can publish in the profile (pinned session code, live approved Skill resources). Existing-source imports retain their source-read approval, workspace/user scope, install-only, status and cancellation. GitHub imports and downloading creator guidance require network access; local directory/ZIP imports do not.

No private repository login, arbitrary webpage scraping or RAR/7z/tar. Remote ZIP files must be downloaded locally first. Existing differing contents are never overwritten. Approvals, filesystem rules and resource registration remain controlled by Agnes. Previously installed personal packages are not silently migrated or removed.

On GitHub API rate limits, public repository imports use a pinned commit archive with the same bounded public network policy and ZIP validation. Archives above the 2 MiB public-fetch limit still require local ZIP import. Existing installed helper packages are not automatically upgraded; update the installed package to receive this fix.

The four tools are skill_helper_import, skill_helper_creator, skill_helper_create and skill_helper_install. For installed instruction drafts and imported resources, ready takes effect next turn; prepared/running are not success. Authored candidates require passing tests and exact-hash human review; published preserves pinned session code while approved Skill resources refresh live, and retains agent session/turn provenance. Installation does not execute third-party scripts. Removing the helper does not delete already installed skills.

MIT license retained in LICENSE. Runtime implementation is vendored from the locally developed Skill Helper and maintained here with Agnes.

Version 0.3.0 retains static `agnes.contributions` entries of kind `skill` for code-bearing candidates, without a runtime JavaScript entry. Candidate trees are limited to 64 files, 128 KiB per UTF-8 file and 256 KiB total, including generated metadata and tests. Instruction-only drafts retain the Host installer limits and confirmation above. Creation names use lowercase kebab-case (up to 48 characters). Existing import limits are unchanged. Update an already installed helper explicitly to receive these changes.

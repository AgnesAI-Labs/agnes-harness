# AGH Plugin Helper

A default, removable AGH plugin for creating tool, tool-with-panel, Skill and pure CSS skin plugins in conversation. Read the guide, create a private Host candidate, run exact-hash Node tests with explicit permission, then submit for publication (automatic under full access; human review otherwise). Full-access submission installs, trusts and enables through the standard publication transaction. Settings → Plugins shows file diffs, tests, capabilities, the installed base and agent session/turn. Human approval binds the candidate and review hashes; any edit invalidates it. Normal package publication creates a new generation while existing sessions retain theirs.

The initial authoring flow uses the same bounded text-candidate contract as the builtin scaffold, including its TypeScript panel template. Creating a candidate never executes lifecycle scripts. Only a human can publish or replace an installed package after reviewing its base hash. It does not bypass AGH file/permission policy. Inspection checks the package contract; it is not a security audit of JavaScript. The test confirmation explains that candidate Node code executes on the machine; it is not a hostile-code sandbox. Tests do not run npm lifecycle scripts. Existing installed helpers are not silently upgraded: update to the helper shipped with this release for the candidate workflow.

For a skin, read `plugin_helper_guide` with `kind: skin`. Its complete template uses `agnes.plugins` and a row-bound `clientDescriptors` file. Select the installed skin in Settings → General → Appearance, verify light/dark modes and disable recovery. Backend status does not verify browser appearance.

Both guides embed the same source-generated author reference (public PluginContext/ToolContext, storage choices, complete skin token/region lists). Choose `tool-with-panel` for tool plus UI; add missing capabilities to the same candidate. Read → write only changed files with `mode: "merge"` (optional `remove` deletes existing paths) → plugin_test on the final hash. `plugin_helper_write` aliases `plugin_candidate_write`; both require `candidateId` and `expectedHash`. Default `replace` is a complete-tree rewrite. Use public author APIs/reference; never search Host/installed source, other workspaces, environment variables or credentials. Use `@agnes/host/author-testkit` for real Host registration/invocation; hand-made context mocks do not verify installation.

两条指南共用源码生成的作者参考，包含真实上下文、存储选择和完整皮肤合同。工具加界面选 `tool-with-panel`，已有候选直接补齐能力。读取后用 `mode: "merge"` 仅写变化文件，`remove` 显式删除已有路径，最后对最终摘要运行 plugin_test；默认 replace 仅用于完整重写。只用公开作者 API 和参考，禁止翻查宿主／安装源码、其他工作区、环境变量及凭据；手造上下文测试不算安装验证。

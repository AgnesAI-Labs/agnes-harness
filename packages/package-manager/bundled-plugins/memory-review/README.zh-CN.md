# @agnes/memory-review

[English](README.md) | 简体中文

Apache-2.0 官方**可选**工作区记忆整合插件，内置目录可发现，不会自动安装、信任或启用。

在设置的插件目录安装、信任并启用，将工作区记忆设为**写入前询问**，再新建会话选择 Loop `agnes.memory-review@1.0.0`。请求识别重复、矛盾或失效偏好，在工作台检查来源哈希、修订和**完整差异**，然后进入现有逐文件记忆审批。完全访问不授予记忆许可；关闭阻止读写；本流程在入口拒绝自动模式。

独立 `memory-review` Skill 与分阶段 Loop 只使用公开 plugin-runtime、Loop turn view 和 Host 受控文件端口。三个内部工具不进入模型发现列表。面板使用共享 web-ui、中英文本、键盘控件和授权 SDK 完整工具记录，卸载时释放注册。不增加 Core/Host 接口、直接文件访问、记忆 provider、全局存储或报告导出。

主题先提交、索引最后提交；停用主题保留依据墓碑。多文件写入不保证原子性，主题成功而索引失败显示 **partial（部分提交）**。请检查现有文件并在新一轮对话核对；刷新回执不会重试写入。CAS、同 turn 快照、取消、预算和凭据样式文本拒绝仍由 file provider 维护。AGENTS.md 和已授权知识源优先于模型建议。

每次最多 16 个现有平铺 Markdown 文件、128 KiB 内容、16 组发现和八次替换。不跨工作区合并、不改用户记忆、不后台整合、不创建新主题。历史会话固定后台版本，旧版不兼容记录显示降级提示。配置的模型会收到所选记忆；现有隐私过滤使遥测与会话导出仅保留结构信息。

完整安装与故障语义见仓库 `docs/guide/memory-review.zh-CN.md`。memory-file 与 plugin-runtime 单测使用离线 fixtures 和假模型验证审批发布与恢复，目录测试验证安装后仍停用且未信任。不包含其他项目的代码、提示词或资产。

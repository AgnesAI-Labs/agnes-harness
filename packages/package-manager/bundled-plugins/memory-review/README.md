# @agnes/memory-review

English | [简体中文](README.zh-CN.md)

Official **optional** workspace-memory consolidation plugin, Apache-2.0. Available in the built-in catalogue; never automatically installed, trusted or enabled.

Install, trust and enable Memory review in Settings → Plugins, set workspace memory to **Ask before writing**, then start a new session with Loop `agnes.memory-review@1.0.0`. Ask it to identify duplicates, conflicts or obsolete preferences. Inspect the workbench panel's source hashes, revision and **complete** diffs. Proceed to the existing per-file memory approvals; Full access grants no memory permission. Off blocks reads and writes. The workflow refuses Automatic at entry.

The independent `memory-review` Skill and staged Loop use only `@agnes/plugin-runtime`, the public Loop turn view and Host-mediated file ports. Three internal tools are hidden from model discovery. The panel uses shared web-ui components, en/zh-CN labels, keyboard controls and complete authorized SDK tool details. Uninstall releases registrations. No Core/Host seam, direct file access, memory provider, global store or report export is introduced.

Topics commit before the index. A retired topic retains a provenance tombstone. Multi-file writes are not atomic: a committed topic plus failed index is **partial**. Inspect current files and begin a fresh turn to reconcile; refreshing the receipt never retries writes. CAS, same-turn snapshots, cancellation, native budgets and credential-like-text rejection remain owned by the existing file provider. AGENTS.md and authorized knowledge sources outrank suggestions.

Limits: 16 existing flat Markdown files, 128 KiB inspected content, 16 groups and eight replacements. No cross-workspace merging, user-memory writes, background consolidation or new topic creation. Existing sessions keep pinned backend code; older incompatible UI records degrade visibly. Configured models receive the selected memory; privacy filtering keeps telemetry and session exports structural.

See the repository guide `docs/guide/memory-review.md` for setup, exact failure semantics and privacy boundaries. Offline fixtures in the memory-file and plugin-runtime unit tests cover reviewed publication and fake-model workflow recovery; catalogue tests cover installation disabled and untrusted. No competitor code, prompts or assets are included.

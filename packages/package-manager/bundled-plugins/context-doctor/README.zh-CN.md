# 上下文诊断

[English](README.md) | 简体中文

`@agnes/context-doctor` 是官方可选插件，随内置目录分发，**默认停用**。在“插件 → 目录”安装，审核能力、信任并启用，然后新建包含此插件的会话，在工作台打开“上下文”。

它不增加模型工具，也不调用模型。它只观察 `context`、`before_request`、`before_compact`、`compact`，在自己的会话命名空间记录有界元数据 projection，通过只读 `context.read` 查询供面板显示。不申请文件、网络、凭据、进程、输入投递或管理权限。会话关闭时清理实时状态；卸载撤销 hook、服务、projection、面板和语言注册。已写入的元数据遵循正常会话账本保留规则。

概览分别显示仓库规则（`agents-md`）、工作区记忆（`memory:index`）和其他已观察段落的 UTF-16 字符数。每段以 `ceil(length / 4)` 估算 token，并展示 Surface 估算、缺少估算的节点、固定节点、工具结果数量、模型槽位和工具名数量。**中英文都不是供应商 tokenizer 实测**。缺失段落和配置预算显示未知，不能理解为零或已关闭。hook 只看到此前运行的贡献者，不代表最终请求。

压缩页显示最近一次观察的窗口、预留量、替换序号范围与压缩前后估算。固定节点保留和工具调用/结果配对继续由 Core 负责；压缩后的核验、实际 wire token、具体省略原因和卸载字节数均显示**未知**。工具结果节点可能只包含 artifact 引用，其估算无法解释原始输出体积。出于隐私考虑，不记录模型名与任意自定义槽位字符串。模型切换后，历史压缩窗口不代表当前模型。

持久元数据不含正文、路径、任意段落 ID/来源、工具名、模型标识、采样值或自定义压缩指令，仅含固定分类和数值。projection 与查询上限 32 KiB；实时缓存最多保留 64 个会话/分支快照。查询只接受 `{}`，由 Host 绑定当前会话与分支，不接受浏览器提供的会话 ID。

当前已安装插件的 hook 不能通过 projection reader 读取自己的 projection，因此面板仅展示实时观察，不重建历史或调用私有接口。重启、缓存淘汰或打开旧历史后，在新 hook 运行前显示未知。旧后端、停用或缺少后台行时显示可读失败并可刷新。历史读取与精确 wire 归因等待 后续授权只读诊断接口，本插件不新增 Core/Host 接缝。

详见[使用指南](../../../../docs/guide/context-doctor.zh-CN.md)。独立实现，采用 Apache-2.0；未复制第三方代码、提示词或素材。`src/client.js` 直接使用 Host 提供的 React 与 web-ui 导出。

# 业务配方

[English](README.md) | 简体中文

`@agnes/business-recipes` 是官方**可选、默认关闭**的发现插件，仅提供 profile 首页入口，不增加会话工具。在内置插件目录安装、审查、信任并启用后，Agent FDE 会显示“业务配方”链接，侧边栏也可打开同一页面。停用或卸载会释放入口、语言注册和订阅。

精选三个分别安装、分别固定版本的插件包：

| 配方 | 合成输入 | 产出样例 |
| --- | --- | --- |
| `@agnes-recipe/support-intake` | `ticket-104` | P2 客服分流和回复草稿 |
| `@agnes-recipe/invoice-review` | `invoice-207` | 发票 120、账本 100，差额 20 |
| `@agnes-recipe/meeting-brief` | `meeting-309` | Morgan 审查试点清单，截止 2026-11-02 |

参数仅限列出的 fixture 和中英文选项，映射到不可变的 `metadata.launches` 声明，不通过任意文本插值选择来源、模型、权限或 bundle。每个配方需要已配置的 `standard` 主模型路由；仅在所选 bundle 增加一个只读样例工具和 Skill，产出会话内草稿。无客户系统连接器、文件写入、上传、消息发送或任务创建。模型文字是审查草稿，不代表业务动作已发生。

1. 打开页面，区分“未安装”“已安装 · 未信任”“已信任 · 未启用”“可启动”。旧后台缺少信任字段时显示“信任未知 · 需要审查”。
2. 点击“审查插件”，阅读版本、完整性、声明权限和能力哈希；只有点击“确认安装、信任并启用”才会改变插件状态。
3. 选择输入和语言，点击“审查启动”，核对后台返回的 bundle、预设和 JSON 提示词。
4. 点击“启动此审查后的运行”。适用通常的模型准入与费用；打开生成的会话查看草稿和请求记录。
5. 丢失回执时先“查询操作回执”；重试保留相同 ticket 和 operationId。未知结果不会自动重放。关闭审查不会取消已准入的会话。

审查时效、父依赖及信任检查、bundle/预设校验、会话和耐久输入幂等由现有示例 facade 负责，不引入管理传输或新市场。模型/配置缺失时，请在模型与账户或插件页面修复，再重新审查启动。停用依赖会立即撤销启动权限，刷新显示子插件的当前状态。升级后历史会话保留原后台快照，当前界面不会替换其代码。不需要 G0 新合同。

参见[使用指南](../../../../docs/guide/business-recipes.zh-CN.md)。离线单测覆盖参数、假模型成功/失败、取消、丢失回执与清理；真实模型质量、浏览器布局和发行打包另需集成验证。

在仓库根目录运行合成演示，无需模型账户或密钥：

```sh
pnpm exec vitest run packages/package-manager/bundled-plugins/business-recipes/test/recipes.test.ts --project fast --maxWorkers=1
```

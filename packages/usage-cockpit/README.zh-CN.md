# 用量驾驶舱

[English](README.md) | 简体中文

官方可选插件 `@agnes/usage-cockpit`，默认关闭。从内置目录安装，审阅并信任后启用。
在主页导航打开“用量”，或在选中会话的工作台中打开用量面板。

插件仅通过已认证的 SDK UI 投影读取当前选中会话，不增加模型工具、计费规则或后台收集器。
参见[使用指南](../../docs/guide/usage-cockpit.zh-CN.md)。

会话总额直接使用后端账本投影，由后端负责请求/effect 去重、累计用量和费用调整。
额度与美元分开显示，供应商报告、估算和未知金额保留来源。迟到或中断调用的已记录费用继续可见。

调用分类包括主模型、摘要、审查、旁路调用、父会话记录的子任务费用和其他调用。
明细按轮次调用的 effect ID 去重，可关联的正负调整应用到原费用，不重复统计 token。
这些金额已包含在会话总额中。轮次调用投影之外的记录、无法关联的调整和缺失调用的归属保持未知。缺少 usage 的旧投影显示未知。插件不读取子会话、未接管子会话
或其他所有者的数据，也不声称提供完整任务树账单。

停用或卸载会撤销导航、面板、卡片、语言目录和订阅。不写入计费账本，不改变预算准入。
浏览器仅保留派生视图，重新打开时从授权投影回放。

维护者：执行 `pnpm --filter @agnes/usage-cockpit build:client`，从 TypeScript 重新生成
`src/generated/client.js`。运行时仅导入现有公开平台接口，不嵌入第三方实现、提示词或素材。

离线检查（合成记录与虚构模型身份，无需密钥）：

```sh
pnpm exec vitest run packages/usage-cockpit/test --project fast --maxWorkers=1
```

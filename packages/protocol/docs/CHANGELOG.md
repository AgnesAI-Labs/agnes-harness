# Protocol changes

## Unreleased

- Conversation voice (additive). Client tier: `_agnes/v1/session.voice.transcribe` (`{ sessionId, audio, language? }` → `{ text }`; `audio` is base64 16 kHz mono 16-bit WAV of at most 20 s, schema cap 900,000 characters) and `_agnes/v1/session.voice.speak` (`{ sessionId, text, voice?, speed? }` → `{ audio, mimeType: 'audio/mpeg' }`; `text` is 1 to 120 UTF-16 units, the mp3 at most 1,024,000 base64 characters), both owner only, with omitted `language`, `voice` and `speed` taken from the voice settings; `_agnes/v1/voice.status` (`{}` → `VoiceStatusResult`: `transcribe` / `speech` as `VoiceFeatureState` `available | unconfigured | no-model | credential-missing | ambiguous`, the chosen `account { route, label }`, `reason` `no-account | credential-missing | ambiguous` and the settings) needs no session. Per session at most 1 transcription and 2 speeches run at once (`SESSION_BUSY`, `reason` `voice.transcribe` / `voice.speak`) and 30 calls a minute (`OVERLOADED`, `reason` `VOICE_RATE`, `retryAfterMs`); a call is aborted after 30 s (`VOICE_CALL_TIMEOUT_MS`; clients wait `VOICE_LINK_TIMEOUT_MS`). Refusals: `SEMANTIC_REJECTED` with `reason` `VOICE_UNAVAILABLE` (and `state`), `BUDGET` or `VOICE_PROVIDER` (`data.code` the provider code, `retryable`, `retryAfterMs?`), `INVALID_PARAMS` with `VOICE_TOO_LARGE` / `VOICE_AUDIO_FORMAT`, `REQUEST_TIMEOUT`, and `INTERNAL_ERROR` `VOICE_SETTINGS_UNAVAILABLE` when the settings or accounts cannot be read. Each provider call writes one `side-call` cost row labelled `voice.transcribe` / `voice.speak`. New defs `SessionVoiceTranscribeParams/Result`, `SessionVoiceSpeakParams/Result`, `VoiceFeatureState`, `VoiceStatusResult`; constants in `voice.ts`. An older daemon answers method-not-found.
- Voice settings (additive). Admin tier, local connections only (`CAPABILITY_DENIED` otherwise): `_agnes/v1/voice.settings.get` (`{}` → `VoiceSettingsSnapshot { settings, revision }`) and `_agnes/v1/voice.settings.save` (`{ settings, expectedRevision }` → the new snapshot; a stale revision is `SEMANTIC_REJECTED` `CONFIG_REVISION_CONFLICT`, an invalid value `CONFIG_INVALID_INPUT`). `VoiceSettings` = `{ account, input: { enabled, language, autoSend, maxSeconds }, reading: { enabled, voice, speed, autoRead }, conversation: { pauseSeconds } }`, defaults `DEFAULT_VOICE_SETTINGS` (frozen; clone before changing). `ConfigModel.audioRole` and `ModelRecord.audioRole` (optional `transcribe | speech`) mark a voice account's models.
- `Provider.audio` (optional, additive): `ProviderAudioFacts { wav(base64), units(payload) }`, the payload facts of the payload-only audio adapter, so a caller can check and size a voice payload without the AI package. A provider without it serves no voice calls.
- `ToolMeta.requiresUser` (optional boolean, additive): the tool asks a person who is present or shows them something to act on now. A turn opened by a prompt that declares nobody attending does not offer it to the model or execute a model call to it. That declaration is `session/prompt` `_meta["ai.agnes.harness"].unattended: true` (a non-boolean is `INVALID_PARAMS`); the daemon records it on the turn's input as the actor attribute `interaction: "unattended"`, and the turn's model context gains an unattended-run live note. An older daemon ignores the field.
- `_agnes/v1/session.setToolFilter` (client tier, additive): `{ sessionId, commandId, allow?, deny? }` narrows the tools a session may use for the rest of its life and returns `{ effectiveFromSeq, filter }` with the merged filter. Owner only, idempotent on `commandId`; each list is 1 to 128 exact tool names, an unknown name refuses the whole request (`SEMANTIC_REJECTED`, `data.code` `TOOL_FILTER_REJECTED`). It only narrows and accumulates, and each request is one ignorable `x/core/tool-filter` ledger row that opening a session folds in seq order (a row that cannot be read refuses the open). `session/new` may carry the first request as `_meta["ai.agnes.harness"].toolFilter`. Tools it turns off report `enabled: false` in `session.tools` capabilities with the reason `{ source: { layer: "session", name: "tool-filter" }, rule: "session-deny" | "session-allow" }`. New defs `SessionToolFilter`, `SessionToolFilterRequest`, `SessionToolFilterName(s)`, `SessionSetToolFilterParams` and `SessionSetToolFilterResult`. An older daemon answers method-not-found and ignores the `_meta` field.
- Additive support for model calls that carry a structured payload instead of conversation messages. `RequestBody.payload` (optional) is any JSON value; the lower bound of `RequestBody.timeoutMs.firstToken` and `total` drops from 1000 to 100 milliseconds. `EffectIntent.kind` and `CostLedger.purpose` gain `side-call` (a `side-call` effect is never replayed, like `media`), as do `UITurnCall.purpose` and `UISpan.purpose`. `CostLedger` gains the optional audit fields `route`, `adapter: { id, version? }` and `endpointHost`; rows without them are unchanged. `Provider.describeRoute?(route, model)` (optional) reports the adapter identity, wire API, endpoint host and a digest of the routing configuration. The adapter catalog (`SessionAdapterCatalogResult`, `AdminModelAdapter`, `isAdminModelAdapter`) accepts the optional boolean capabilities `payload` and `payloadOnly`.
- `_agnes/v1/session.revealWorkspace` (client tier) accepts only `{ sessionId }` and returns `{ opened: true }` once the native directory opener starts. Only an authenticated local Unix/loopback-Web session owner may call it. The daemon revalidates that session's authoritative workspace binding; remote connections, missing/stale workspaces and headless desktops are refused. No client path or shell command is accepted. `initialize` adds optional `_meta.agnes.platform`; SDK `InitializeInfo.platform` exposes this daemon fact for native action labels.

- Preset documents lose their retired spellings: `model.retry.backoff_ms` (use `base_delay_ms`), `recovery.unknown_child: park` (use `human`), the document-level `model.id` pin map (pin a model in the slot's `model.route.<slot>: { route, model }`) and the command-policy action `ask` (use `require_approval`). They are refused as invalid preset input instead of being rewritten.
- `SessionDefaultsState.defaults` (`_agnes/v1/sessionSelection.defaults.get/save`, the admin defaults routes and the persisted configuration) selects in the one `providers.<kind>` form: `{ preset?, providers?: { loop?: { provider, version }, 'model-adapter'?: { provider, version } }, model? }`. It replaces `loop: { id, version }` and `modelAdapter: { id, version, model }`; `model` is valid only beside `providers.model-adapter`. The SDK helpers `defaultLoop` and `defaultModelAdapter` read the exact identities back.
- `PluginGenerationStatus.blocked` (optional, additive): `{ file, reason }[]` for the durable pin or head records the Host cannot read, with `file` relative to the profile directory. Present only while one is damaged; generation collection removes nothing while it is.
- `CompositionPatch` selects providers only in `providers: { loop?, 'model-adapter'?, compaction?, persistence?, sandbox? }`; the top-level `loop`, `model-adapter`, `compaction`, `persistence` and `sandbox` patch keys are refused with the sentence that names the table. A profile manifest's own `composition` still cannot carry `providers`.
- `PresetDoc.providers` (optional): the preset's `providers.<kind>` table (`tool-runtime`, `tool-policy`, `loop`, `model-adapter`, `compaction`, `persistence`, `sandbox`). It replaces the top-level `tool-runtime` / `tool-policy` preset keys and the provider keys of a preset's `composition`, which a preset can no longer carry. `model.system_prompt.provider` is the one provider selection that stays inside its configuration object.
- `SessionRuntimeDescriptor.loaded` (required): false for a session no container has open. Such a descriptor is built from the durable generation pin and composition record only; `preset`, `loop`, `resources` and `policy` are now optional and absent when they cannot be derived without loading the session, and `providers` is empty. Nothing is read from the current Host's configuration.
- `SessionViewResult.history.scan` (optional): `{ reason: 'events' | 'bytes' | 'time' | 'cancelled', fromSeq, throughSeq }`. Present when `session.view` stopped scanning at its event, byte (encoded event size) or time budget, or because the caller cancelled; the timeline covers only the rows `fromSeq`..`throughSeq`. A session over budget is read from its newest row backwards, so the rows not shown are the older ones. A reader that does not return is abandoned at the deadline or the cancel.
- `_agnes/v1/session.view` (client tier): reads a session's recorded conversation without opening it, so a session this build cannot continue (newer or older version, missing pinned provider, damaged ledger) stays viewable. Adds `SessionViewParams`, `SessionViewResult` and `SessionViewNotice`. Nothing is restored, locked or written; a damaged ledger returns the rows that decoded safely plus a `notice`.
- `_agnes/v1/sessions.migrate`: optional `repin` (pinned seam kinds the administrator agrees to replace) on the params and optional `repinned` on the result. A migration that would replace a pinned seam implementation without naming it fails with `E_SEAM_PIN_CHANGE`.
- App Server error causes `E_SESSION_VERSION_NEWER`, `E_SESSION_VERSION_OLDER`, `E_SESSION_CORRUPT`, `E_SEAM_PIN_MISMATCH`, `E_SEAM_PIN_CHANGE` and message keys `appServer.errors.sessionNewer`, `sessionOlder`, `sessionCorrupt`. `sessionVersionNotice()` gives the bilingual text and the follow-up actions.
- `RuntimeProfileManifest.providers` is the one selection table: `providers.<kind>: { provider, version? }` for the seven seam kinds (`SeamSelection`) and for `loop`, `compaction`, `model-adapter`, `persistence`, `sandbox`, `tool-runtime`, `tool-policy`, `child-agent` and `memory` (`ProviderSelection`). It replaces the manifest keys `seams`, `persistence` and `sandbox.provider`; `sandbox` keeps only `options`. `ResolvedProfile` and the lockfile are unchanged.
- Profile and lockfile `seams`: the seven seam kinds are `{ provider, version? }` (`SeamSelection`); `seams.ledger` is `seams.billing`, `seams.harness` is gone.
- `RuntimeAdminSnapshot.providers[]`: `required` and `pinned`.
- `approvals.mode` loses `smart`; the `approval/guardian-decided` event is removed.

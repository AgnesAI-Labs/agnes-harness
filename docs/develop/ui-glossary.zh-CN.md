# 界面术语

[English](ui-glossary.md) | 简体中文

标签、帮助、无障碍名称、确认和错误信息统一使用下表。标识符、来源引用、命令和第三方显示名称保持原样。

| English | 简体中文 | 含义 |
| --- | --- | --- |
| Skill | 技能 | 随包或工作区提供的指令资源 |
| MCP | MCP | Model Context Protocol 服务 |
| Plugin | 插件 | 可安装的软件包 |
| Provider kind | 插件类型 | 运行实现的类别 |
| Provider | 插件实现 | 已注册的运行实现；模型账户使用“模型服务” |
| Child agent | 子代理 | 属于会话的子任务执行 |
| Agent Loop | Agent Loop | 会话执行流程，中文标签不交替使用“Loop”或“循环” |
| Bundle | 组合包 | 命名的会话组合 |
| Preset | 预设 | 命名的权限或配置预设 |
| Plugin generation | 插件代际 | 不可变的运行代码代际；软件包版本仍称“版本” |
| Credential reference | 凭据引用 | 对凭据库的引用；内部 `secretRef` 字段名不改动 |
| New session | 新会话 | 修改默认值或启用插件后创建的会话 |

默认选项显示解析后的友好名称，标识符和版本作为次要信息，提示说明来源。目录读取失败时保留草稿选择。日期和数字按当前语言格式化；后台错误按错误码翻译，未知错误使用本地化的通用失败信息。操作提示保存翻译键，切换语言也更新已打开的弹窗及已有反馈。

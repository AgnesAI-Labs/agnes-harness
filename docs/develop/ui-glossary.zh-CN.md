# 界面术语

[English](ui-glossary.md) | 简体中文

标签、帮助、无障碍名称、确认和错误信息统一使用下表。标识符、来源引用、命令和第三方显示名称保持原样。

| English | 简体中文 | 含义 |
| --- | --- | --- |
| Skill | 技能 | 随包或工作区提供的指令资源 |
| MCP | MCP | Model Context Protocol 服务 |
| Plugin | 插件 | 可安装的软件包 |
| Provider kind | 插件类型 | 运行实现的类别 |
| Provider | 插件实现 | 已注册的运行实现；模型账户使用“模型服务” |
| Child agent | 子代理 | 属于会话的子任务执行 |
| Running mode (Loop) | 运行方式（Loop） | 有多项可选时才显示，技术名称保留在括号里 |
| Bundle (advanced) | 组合（高级） | 可复用配置；智能体须有自己的 launch |
| Preset | 预设 | 执行配方：工具、提示、模型槽位和预算；权限单独选择 |
| Updating | 更新中 | 可行动的更新状态；保留版本放入详情 |
| Saved credential | 已保存的凭据 | 通过选择器选择；内部 `secretRef` 字段名不改动 |
| New session | 新会话 | 修改默认值或启用插件后创建的会话 |

目录读取失败时保留草稿选择。日期和数字按当前语言格式化；后台错误按错误码翻译，未知错误使用本地化的通用失败信息。操作提示保存翻译键，切换语言也更新已打开的弹窗及已有反馈。

日常页面使用下列术语，标识符、路径、哈希、代际、传输协议等进入「技术详情」，遗留占用只出现在诊断。会话用标题与工作区选择，凭据用选择器。

| English | 简体中文 | 含义 |
| --- | --- | --- |
| Activity record | 执行记录 | 请求、工具、产物的关联记录 |
| View | 界面 | 使用界面自身标题，无标题时的兜底 |
| Edit workspace | 可修改工作区 | 工作区修改权限 |
| Local command / Remote service | 本地命令 / 远程服务 | MCP |
| Leftover usage | 遗留占用 | 仅诊断 |
| Refresh | 刷新 | 图标与提示 |

默认选择显示友好名称；ID、版本、来源等进入详情或提示，读取失败保留草稿。

| English | 简体中文 | 用法 |
| --- | --- | --- |
| Agent | 智能体 | 带显式 launch 的组合 |
| Application | 应用 | 显式采纳的身份与展示 |
| Page | 页面 | 追加的完整页面 |
| View position | 视图位置 | 既有区域里的贡献 |
| Tool result card | 工具结果卡片 | 展示工具证据 |
| Interaction card | 交互卡片 | 受授权的结构化交互 |
| Settings section | 设置分区 | 宿主设置中的分区 |
| Takeover | 接管 | 替换选中的呈现角色 |

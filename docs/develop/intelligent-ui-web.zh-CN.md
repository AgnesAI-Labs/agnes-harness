# Intelligent UI Web 渲染器

[English](intelligent-ui-web.md) | 简体中文

[合同](intelligent-ui.zh-CN.md) · [前端](frontend.zh-CN.md)

Web 渲染器消费生成的 Intelligent UI 协议。真实业务流程需要后端方法和官方插件可用；挂载界面不会执行工具。不接受生成的 HTML、JavaScript、CSS 或远程组件。

每个会话只有一个 surface 客户端，由紧凑的对话卡片和 **交互界面** 工作台面板共用。面板优先列出进行中的界面，并保留最近关闭的视图。展开指向同一会话、surface 和版本。表单与行选择共享草稿；版本变化会丢弃草稿，并要求核对当前数据。未保存草稿仅保存在内存中，刷新后恢复服务端的已提交数据。

业务操作打开确认视图。确认仅提交声明的 action id、当前版本、表单值与行 id。工具权限另行审批：等待审批状态链接现有审批 UI 和原 ticket。已接收和执行中的操作禁用新的提交。成功显示持久回执摘要；客户端等待 Agent 更新，不自行编造新行或新版本。仅明确标记可重试的失败提供携带 `retryOf` 的新确认尝试。结果未知时保持锁定，直到后端效果对账提供新证据。

客户端先监听再读取恢复分页，检查一致的账本水位，并缓冲并发事件。它保留对话共用的事件订阅和游标，在 UI 事件、事件缺口与重连时重新读取投影，对无效或缺失证据默认拒绝。分页失败会在有限次数内重新开始读取。不支持的方法显示不可用状态。

命令尚未解决时，command id 和不可变请求保存在会话范围的浏览器存储中。**恢复提交** 先读取原回执，仅在回执不存在时重发同一个命令，不创建新决定。过期或关闭拒绝显示 **数据已变化，请重新确认**。查看当前数据会读取最新版本，丢弃旧草稿和旧确认；仅当界面仍打开且未锁定时，才允许新的明确决定。

目录位于 `packages/web-ui/src/intelligent-ui`；客户端与两处注册位于 `packages/web/src/intelligent-ui`。SVG 图表提供包含数值的明细表，不推断货币单位。控件具有英文和简体中文目录、原生键盘操作、回执实时播报和稳定 test ids。两条 Web 构建路径将目录样式追加到已有 `/style.css` 资源。

单元测试使用假 App Server。`tools/e2e-web/intelligent-ui.spec.ts` 启动隔离的浏览器 fixture，使用真实目录、共享客户端、工作台 dock 和审批组件，覆盖行选择、表单编辑、双位置共享、重复点击、审批中刷新、成功后版本更新和过期后的再次确认。它不能证明后端授权、业务工具校验或效果恢复；这些需要与插件验收套件联调。

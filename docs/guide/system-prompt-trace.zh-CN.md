# 系统提示词与模型请求轨迹

[English](system-prompt-trace.md) | 简体中文

## 自定义角色

打开 **设置 → Agent → 系统提示词**，添加开场指令、结尾指令或回复风格，再选择 **保存供新会话使用**。默认配置属于当前 profile。Bundle 可提供 `preset.model.system_prompt`，profile 字段覆盖对应的 Bundle 字段。重置会恢复 Bundle 默认值。

每个自定义字段最多 8,192 个字符。高级完整替换最多 65,536 个字符，需要明确确认。它替换插件与仓库指令节，Core 的记忆事实与运行时上下文仍保持动态；与开场、结尾、回复风格字段冲突，保存前必须清空这些字段。组合器返回重复节标识时会拒绝。Core 保留不可信输入边界；权限、工具 schema 和 ledger 仍是事实源。移除工作流指令可能降低可靠性。

新会话保存配置、提示词 provider 的标识及版本和初始组合提示词哈希。daemon 重启后的恢复读取固定配置；缺失 provider 时会拒绝，不会替换成其他 provider。引入固定配置之前创建的会话继续使用默认值。运行时上下文、仓库规则、记忆与 Skills 仍可在轮次之间更新；角色配置的固定不会冻结这些内容。

**当前配置预览** 与编辑器并排，显示随插件提供的节及友好的来源名称；悬停可查看记录的原始标识。**此会话实际版本** 显示最近一次保留的逻辑请求提示词及运行时节；没有保留采集时，明确标注使用该会话固定配置和当前动态节组合的预览。这些预览与最终发送正文分别标明。`@agnes/code` 的 `system-prompt:default` 插件可独立替换，使用公开的 `systemPromptKind` 合同。

## 查看模型调用

打开 **轨迹**，筛选助手条目并选择调用。六个页签为 **系统提示词**、**工具**、**消息**、**参数**、**Token** 和 **原始 JSON**。前四项显示 Core 推导和压缩后的逻辑请求，来源区分固定指令和动态节。顶部摘要显示模型、所选发送尝试及状态、实际与估算 Token 和采集时间。调用选择器分别列出任务、标题与压缩调用。既有轮次与步骤分组、折叠输出、筛选和聊天跳转继续可用。

**最终发送的 JSON** 是适配器最终 HTTP fetch 接点观察到的脱敏正文，位于 SDK 序列化与兼容转换之后。它不包含认证 header，也不是网络抓包。**逻辑请求** 表示最终正文没有可用的采集接点；原始 JSON 显示明确不可用类型，不能用逻辑对象冒充正文。Pi 的 HTTP fetch 路径受支持（Codex 使用 SSE）；社区 WebSocket、Google/Bedrock SDK 传输及无接点适配器可能不可用。二进制数据与过深内容会省略并标注采集不完整。不会存储响应正文。

每次观察到的适配器尝试都有 `attemptId`、逻辑 `parentCallId`、序号和未发送、已发送、失败、取消或完成状态。无接点适配器的发送状态明确标为未知。受支持的 HTTP 重试各自保留最终正文；不支持的传输不能展示其内部 wire 重试。Token 分别标明 provider 报告值、UTF-8 字节数除以四的估算值和缺失。估算不代表账单；零值或未报告的 provider 用量保持缺失。压缩用量属于独立调用，不并入主请求。

采集详情包括适配器及版本、API、移除凭据与查询参数的端点、代码代际 ID、提示词与工具哈希、消息和各来源哈希、记忆 revision/哈希与可见压缩边界。内容哈希基于脱敏内容；会话初始提示词 pin 基于原始组合指令。记忆生产者不提供 revision 时记录 `null`，仍可保留记忆节哈希。重试使用同一逻辑请求快照。

**对比** 选择器默认是 **无**。选择 **上一次请求** 比较当前会话内的请求。跨会话比较时，先在旧请求选择 **将此请求设为对比基准**，打开新请求后选择 **已固定基准**。两个会话都会检查归属。基准仅在页面打开期间保留。**复制** 是明确的剪贴板操作，请先检查内容。

## 隐私与保留期

请求正文保存在 `AGH_HOME` 下的私有本地存储中，按 profile 和会话隔离。传输接点不采集凭据；持久化前对值脱敏并校验。秘密识别采用启发式规则，不能保证识别全部敏感文本。请求与记忆内容不会进入遥测或诊断导出；普通投影仅携带 ID、哈希和大小。

内容寻址 blob 对系统文本、节元数据、工具 schema 和最终正文去重。每次调用上限 2 MiB，每个 profile 为 64 MiB、256 次调用，每个会话为 16 MiB、128 次调用，最长保留七天。超大逻辑采集会跳过，wire 采集不完整会明确标注。近期无引用 blob 仍占用容量时，可能拒绝新采集。

Worker 在启动时、写入后及空闲期间每五分钟回收；关闭 Host 会停止回收器。读取与回收会隔离格式错误的调用元数据，健康采集与保留期回收继续工作。自动 GC 只有在 blob **无保留调用引用且保留期已过** 时才删除。打开采集详情，确认 **删除此调用在本地保留的正文和元数据**，再选择 **清除此采集记录**，立即删除该记录与无共享引用的内容。其他调用仍引用的 blob 会保留。已回收或清除的运行中调用不会被后续响应重新写回。

生成 schema 的 App Server 方法为 `_agnes/v1/systemPrompt.get`、`_agnes/v1/systemPrompt.save`、`_agnes/v1/trace.request` 和 `_agnes/v1/trace.clear`。SDK 提供 `client.systemPrompt.get/save` 与 `client.requestTrace.get/list/clear`。读取默认配置需要服务端授予的、无方法范围限制的本地 `packages.read` 权限；写入需要 `packages.activate` 及健康、可写的配置控制平面。只读管理员可检查默认配置但不能保存。普通 Web 连接没有配置权限，请使用管理桥。会话预览、采集读取、对比与清除检查持久会话归属。管理桥使用固定路由、同源检查与管理员写权限。

## 执行依据

在 trace 调用中点**查看执行依据**、工具行点**查看执行记录**、交付物或产物点**查看来源**，或在插件来源中点**查看起草会话**，会打开同一个工作区面板。标识符、哈希和图元数据默认折叠在**技术详情**中。Escape 关闭面板并将焦点归还入口。

面板只读取已有记录，不执行工具、导入插件代码、重绑会话或改变候选状态。请求使用捕获时的代际，不套用会话当前代际。捕获过期、历史版本不可得、模型与工具之间无法证明的关联都会明确显示缺口。工具结果区分实际返回、拒绝或恢复记录，以及已接收的后台任务。返回产物引用只证明该调用提供了此引用，不能证明谁创建了可变工作区文件。没有外部回执时，外部是否完成为**未知**；此视图不能证明外部操作恰好执行一次。

`_agnes/v1/session.factChain` 在读取元数据前校验会话 owner 和精确 anchor 归属。候选依据还需要既有包读取权限和候选 owner；固定同源管理桥不扩大普通 Web 连接的权限。SDK 提供 `client.factChain(params)` 与 `session.factChain(anchor, laneId)`。读取固定账本最高序号，最多扫描 2,000 条相关记录、4 MiB，并使用五秒扫描预算；投影最多 256 个节点与 512 条边。超出上限会报告不完整。请求捕获独立保留，因此序号边界不是跨存储的原子快照。

工作区扩展可从 `@agnes/web-client` 调用 `factChainLinks.open({ sessionId, laneId, anchor })`。宿主注册打开函数并返回按注册身份清理的 disposer；打开只负责界面导航，不授予数据访问权。文件审阅扩展必须提供已有账本序号与完整产物引用，或真实工具／请求标识；仅凭路径或相同摘要不能建立因果关系。

# 本地前端连接另一台电脑的后端

[English](remote-frontend.md) | 简体中文

[部署](deployment.zh-CN.md) · [插件](packages.zh-CN.md) · [Web 工作台](web.zh-CN.md)

A、B 使用同一套完整标准 Harness。A 托管自己的页面，浏览器直接连接 B 的 HTTP/WebSocket 服务，不使用 SSH，也不经过 A 的 BFF 转发。B 启用已安装的云端插件，A 不需要安装该插件。

## 发布合同

已安装、受信任、已启用的插件注册 profile 级查询服务 `frontend.publish`，并在客户端描述符中声明。服务接收 `{}`，返回：

```json
{"enabled":true,"access":"public-owner","host":"0.0.0.0","port":8443}
```

`public-owner` 明确将当前 profile 的本地工作台权限授予任何能访问端口的调用者，无需登录或连接 Token，不设置来源白名单，也不缩减远程方法集。工作区、工具、设置和插件管理均公开；后端原有的执行规则及工具审批继续适用。这不建立多个用户身份，也不提供租户隔离。

`agh serve` 读取当前就绪的已安装 roster，通过私有连接调用声明的 profile 服务，持有公开监听器，仅转发到自身固定的本机 Web/daemon 端点。在这条显式发布边界，将请求来源转换为本地工作台权限。默认本地监听仍执行原有 Host/Origin 检查；daemon 原有的认证远程 WSS 保持独立，不放宽身份要求。

同一时刻只允许一个发布 owner。声明缺失、停用、阻塞、多个声明冲突或查询失败时不提供远程服务，本地开发文件夹或旧会话 pin 不能开启端口。每个 HTTP 请求和 WebSocket 升级检查当前声明；500 毫秒协调循环在撤权或配置变化后关闭入口和已有连接，Worker RPC 失败时可能额外等待其有界超时。关闭 Web launcher 同样停止发布，在途任务不隐式取消。

可选 `tls: {"certFile":"...","keyFile":"..."}` 指向 B 的证书和私钥文件，同时提供两项后使用 HTTPS/WSS，缺省为 HTTP/WS。HTTP API 和 WebSocket 共用端口。TLS 只加密传输，不增加用户认证。

## 双机操作

1. A、B 构建配套修改后的标准 Harness，通过仓库工具链入口执行 `--filter @agnes/cli build:local`。
2. B 执行 `agh plugins add /绝对路径/agh-cloud-plugin`，审阅并确认，或使用 Web 插件安装界面。保持 B 同一 home/profile 的 `agh serve` 运行。
3. 激活后 launcher 输出 `public-owner frontend: ...`，通过标准插件设置修改 host、端口或 TLS 文件。B 的防火墙允许选定端口。
4. 打开 A 自己的 AGH 页面，在侧栏点击“本地”，填写例如 `http://192.168.1.20:8443`，点击“连接远程”。使用 B 实际可达的地址，不使用监听地址 `0.0.0.0`。
5. 使用 B 已登记的工作区和模型配置创建会话，“使用本地”回到 A。也可以直接打开 B 的公开地址，使用 B 托管的工作台。

浏览器的私有网络许可、混合内容和证书规则仍然适用。HTTPS 页面需要兼容的安全远程端点，不提供关闭证书校验的捷径。

## 客户端路由与状态

页面 `remote` 参数选择 B。在加载控制器前，浏览器通过 `/_agnes/remote-frontend` 检查发布版本、访问模式、实例身份和固定 WebSocket 路径。A 提供自己的前端代码及共享 vendor 模块；后端 HTTP、插件资源和 socket 使用 B。CSP 只增加明确选择的来源及其 WS(S) 来源，不向 B 发送 A 的 Cookie，后端 HTTP 不跟随重定向到其他目标。

切换会刷新独立工作台上下文，清除会话和启动参数。命令 journal、输入草稿和模型／权限记忆按后端来源与实例身份隔离。首版切换完整本地／远程列表，不在同一侧栏混排。文件、插件、MCP 和模型凭证归属各自环境。

第三方分发、购买 Key、模型市场目录和用量计量后续在插件中接入。面向用户的第三方模型目录仍由 A 的标准客户端／BFF 查询，本阶段未实现这些服务。

远端插件界面代码沿用现有受信任插件模型，在 A 的工作台页面中执行。本阶段按环境隔离后端执行与存储，不为这类浏览器代码提供脱离 A 页面权限的沙箱。连接同时选择 B 的后端及其受信任前端贡献。

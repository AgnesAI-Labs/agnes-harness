# 会话工作台

[English](workbench.md) | 简体中文

[文档导航](../README.zh-CN.md) · [Web 会话](web.zh-CN.md) · [执行证据](fact-chain.zh-CN.md)

点击会话顶栏的**工作台**，在对话旁查看**文件、更改、执行记录和终端**。目标与业务界面仅在会话有相应内容时出现；更多面板放在**更多**中。新浏览器默认关闭工作台，侧栏默认宽度为 720px，按可用空间裁切以保留至少 420px 的会话列，已有宽度选择继续保留；可以切换标签、拖动分隔条调整大小，或展开到窗口宽度的 60%，大小与所选标签保存在本地。窄屏使用全屏层。标签支持方向键、Home/End，分隔条支持方向键，Escape 关闭工作台并还焦点。F6 与 Shift+F6 在任务区域间循环。打开终端标签不会启动进程；点击**新建终端**才会启动。终端使用跟随主题的 xterm.js 画面；引导卡箭头或 **+** 的菜单可选择 Shell、连接 Agent 任务。页签菜单（右键或 Shift+F10）提供重命名、中断、详情和终止；双击用户页签名称可改名。用户页签 **×** 结束进程并关闭页签，Agent 页签 **×** 取消跟随。关闭工作台后进程仍运行。输入、刷新和输出限制见[终端与后台任务](web.zh-CN.md#终端与后台任务)。

终端画面加载失败时，可在标签内点击**重试**。面板内容出错后，工作台标签、展开和关闭仍然可用。

浏览器页面隐藏时，更改和终端暂停界面轮询；返回页面后补读最新状态。后台任务和终端进程继续运行。

采用业务应用后，对象按钮和输入区快捷操作会打开经审阅的任务，并显示可移除的上下文 chip。输入框可编辑普通文字；移除 chip 后，后续请求停止附加该上下文。已提交消息的 chip 可在重新加载后恢复。助手回合标题显示处理工作的内部角色；当前对象、签署和证据页签使用应用声明的界面，业务状态与决定仍以工具和宿主为准。

待签署事项在会话卡片中确认，待签署页签显示状态并提供跳转。证据页签列出声明的证据对象与输出文件，产生它的工具保留在详情中。

基础工具在步骤、确认卡片、回执和轨迹中使用当前界面语言的同一名称。工具卡默认折叠；展开命令步骤后，可以查看单次展示的命令、分开的标准输出与标准错误，以及退出码。参数预览另放在**原始参数**中。确认卡片等待操作时，会话中只保留一行紧凑提示并链接到卡片。

## 查看文件

内置文件面板按需列出已准入的会话工作区，遵循受支持的 `.gitignore`/`.aghignore` 子集。未打开文件时，文件树占满面板；打开文件后显示只读预览。A/M 标记的提示分别说明“本次会话新建”和“本次会话修改”。面板顶栏的 **… → 文件可见性规则** 可查看受支持的忽略规则。引用文件只向输入框加入引用的相对路径，不发送消息。Git 标记尽力读取，不可用不代表仓库干净。支持普通仓库，以及使用合法 `.git` 指针文件的 linked worktree 和子模块；Git 元数据为符号链接或格式不正确时显示不可用。读取状态时会禁用仓库钩子和外部内容过滤器；依赖这些过滤器的文件标记可能与手动运行 Git 不同。

预览上限为 1 MiB。二进制、超大文件、符号链接及安装 home 会拒绝或明确标注，不伪装成已读正文。版本描述读取时的字节，不保证后来无人修改；面板不授予任意文件访问或恢复权限。

打开文件后，预览区顶部出现标签条，文件树仍留在旁边。点击文件树或文件引用会切到该文件的标签，而不再替换上一个预览；关闭当前标签后优先激活右侧标签，没有右侧则激活左侧。每个标签各自保留「源码/预览」选择和源码滚动位置，打开列表按会话记在这个浏览器里，切换工作台面板、关闭工作台或刷新页面后仍会恢复。后台刷新读取期间保留当前文件，版本未变时保持预览；刷新、重试和账本更新只重读当前标签，其他标签在选中时再读，期间仍显示上次正文。某个标签读取失败只清空它自己的正文并显示错误，标签保留，可重试或关闭。方向键、Home/End 在标签间切换，Delete 关闭当前标签。最多同时打开 20 个文件，需要先关闭一个才能再开。失去读取权限时，该标签下次读取会清除原有正文；恢复的路径列表本身不授予任何读取权限。

## 核对工作流结果

工作流卡片区分子代理自述与后端执行回执。Worktree 输出仍在子工作区，不会自动合入主工作区。声称已经集成前，核对当前成员状态与回执是否可得，见[程序化工作流](code-workflows.zh-CN.md)。

通过[执行证据](fact-chain.zh-CN.md)检查已有请求、工具和产物关系。路径或摘要相同本身不证明因果关系。

开发者可通过 Host 的 `@agnes/web-client` 中 `workbenchPanels` 添加面板，通过 `fileViewerActions` 添加文件操作入口。注册不授予数据或写入权限。[面板作者指南](../extend/workbench-panels.zh-CN.md)维护 SDK 合同、忽略规则子集与清理要求。

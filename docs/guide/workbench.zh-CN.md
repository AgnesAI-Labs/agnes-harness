# 会话工作台

[English](workbench.md) | 简体中文

[文档导航](../README.zh-CN.md) · [Web 会话](web.zh-CN.md) · [执行证据](fact-chain.zh-CN.md)

通过会话的右侧与底部停靠面板，在对话旁查看文件与执行信息。新浏览器默认关闭面板；打开后可以切换标签、拖动分隔条调整大小或折叠，大小保存在本地。小屏幕使用浮层。标签支持方向键、Home/End，分隔条支持方向键，Escape 关闭面板。

## 查看文件

内置文件面板按需列出已准入的会话工作区，遵循受支持的 `.gitignore`/`.aghignore` 子集。打开文件获得只读预览；引用文件只向输入框加入引用的相对路径，不发送消息。Git 标记尽力读取，不可用不代表仓库干净。

预览上限为 1 MiB。二进制、超大文件、符号链接及安装 home 会拒绝或明确标注，不伪装成已读正文。版本描述读取时的字节，不保证后来无人修改；面板不授予任意文件访问或恢复权限。

## 核对工作流结果

工作流卡片区分子代理自述与后端执行回执。Worktree 输出仍在子工作区，不会自动合入主工作区。声称已经集成前，核对当前成员状态与回执是否可得，见[程序化工作流](code-workflows.zh-CN.md)。

通过[执行证据](fact-chain.zh-CN.md)检查已有请求、工具和产物关系。路径或摘要相同本身不证明因果关系。

开发者可通过 Host 的 `@agnes/web-client` 中 `workbenchPanels` 添加面板，通过 `fileViewerActions` 添加文件操作入口。注册不授予数据或写入权限。[面板作者指南](../extend/workbench-panels.zh-CN.md)维护 SDK 合同、忽略规则子集与清理要求。

# 复核与整合记忆

[English](memory-review.md) | 简体中文

[学习型记忆](memory.zh-CN.md) · [插件生命周期](packages.zh-CN.md)

**记忆复核**（`@agnes/memory-review`）是官方可选插件，用于发现可能重复、矛盾或失效的工作区偏好，并提出带来源哈希、快照修订和完整文件差异的替换候选。发现结果是需要人审的模型建议；AGENTS.md 和已授权知识源始终优先于学习偏好。

## 安装与使用

1. 打开 **设置 → 插件 → 目录**，选择 **记忆复核**，检查来源与权限后安装、信任并启用。插件随内置目录提供，但不会自动安装或启用。CLI 可执行 `node agnes.mjs package add file:./bundled-plugins/memory-review`；信任和启用仍是独立操作。
2. 在 **设置 → Agent → 记忆** 中，将当前工作区设为 **写入前询问**。关闭会拒绝 Agent 读写；本流程在入口也拒绝自动模式，以便逐项人审纠错。插件无法自行开启记忆。
3. 在该工作区**新建会话**，在 Loop 选择器中选择 `agnes.memory-review@1.0.0`。使用普通已配置的对话模型，无须专用账号或新增凭据。选择仅作用于此会话。显式 profile 配置为 `providers.loop: { provider: agnes.memory-review, version: 1.0.0 }`；preset 中可选择配套工具策略 `providers.tool-policy: { provider: agnes.memory-review }`。附带的记忆复核 Skill 名为 `memory-review`。
4. 例如请求：“找出重复偏好和包管理器建议冲突。AGENTS.md 要求 pnpm，请提出保守纠正。”
5. 在会话工作台打开 **记忆复核**。**发现**展示冲突组和来源哈希；**变更**展示完整文件替换差异、原始/新哈希与修订。动态文件列表使用 Select；两个视图使用支持键盘的 Segmented。
6. 流程运行到每个文件时，请检查原生记忆审批。询问模式中，每次写入仍须通过现有的一次性人审，绑定完整差异和原始/新哈希。完全访问和会话级授权不能替代记忆审批。没有依据的纠正应拒绝。

插件通过公开 Loop turn view 读取 Host 生成的 `memory:index` 提示段，并使用普通受控文件端口。旧版后台缺少此段、格式不可用或预算导致省略时，流程会拒绝推断路径。可提高记忆上下文预算，或使用普通记忆编辑器。默认 Loop 不会因此增加模型可见工具。

## 结果与恢复

先替换主题文件，最后更新索引。停用主题会写入保留依据的墓碑内容，不直接删除文件；整合后在记忆文件中保留修订、来源文件哈希与原因。依据仍是不可信学习数据，不构成权威指令。原生记忆预算和凭据样式文本检查继续生效，依据文本也计入预算。

多文件发布**不保证原子性**。主题已提交而索引失败时，面板显示 **partial（部分提交）**，列出已确认文件、失败文件、安全错误码和剩余文件。**刷新回执**只读记录，不重复写入。请先在设置中检查当前文件，再开启新一轮对话核对；不要自动重试或回滚。某文件结果未知表示没有确认提交，不能据此认定文件未变。

审批期间的人工作业会触发 CAS 冲突，并保留人工修改。同一 turn 的索引、主题读取及重试共享快照，已提交纠正从下一 turn 才可读。策略变化或原生审批取消不能发布旧候选；操作人改变记忆配置后，实时 file provider 仍是策略权威。

MVP 每次最多复核 16 个现有平铺 Markdown 文件、128 KiB 内容、16 组发现和八次文件替换；编码后的快照/完整候选最多 240,000 字节，低于工具结果 JSON 上限。超限明确拒绝，请先手动缩减。不创建新主题、不移动记忆、不跨工作区合并、不改用户记忆、不扫描其他会话，也不后台整合。模型质量和偏好是否真正过时仍需人工判断。

## 隐私与卸载

Loop 在任何记忆操作前读取 Host turn view，现有 memory-private 标记将会话导出和遥测限制为结构事实。面板通过当前会话的授权 SDK 读取完整工具记录，不依赖截断预览或全局存储。插件不增加报告产物、遥测流、联网连接器或第二个记忆写入器。所配置模型会收到本次复核的工作区记忆；需要内容留在本机时请使用本地模型。[学习型记忆](memory.zh-CN.md) 中的平台限制仍适用。

可在设置中停用或卸载插件，释放其注册与面板。记忆文件仍由 file provider 管理，可在设置中查看。历史会话保留固定的后台版本，界面来自当前安装版；旧版记录无法读取时显示可理解的降级提示。

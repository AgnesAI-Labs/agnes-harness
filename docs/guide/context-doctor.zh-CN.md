# 解释上下文元数据

[English](context-doctor.md) | 简体中文

[文档](../README.zh-CN.md) · [默认上下文](context.zh-CN.md) · [插件生命周期](packages.zh-CN.md)

官方可选插件“上下文诊断”解释公开 hook 可观察到的上下文元数据。它在内置插件目录中，默认停用，不需要模型密钥，也不向会话增加工具。

1. 打开“插件 → 目录”，安装 `@agnes/context-doctor`，检查能力、信任并启用。
2. 新建 composition 包含此插件的会话。已有会话固定后台代码版本，启用插件不会补装到旧会话。
3. 使用已配置模型运行普通任务，或使用现有离线 scripted 模型 fixture。在工作台打开“上下文”，选择“概览”或“压缩”。Tab 和方向键可切换分段视图；“刷新”重新读取。
4. 概览分别显示已观察的固定规则、工作区记忆和其他段落。发生压缩后，压缩页显示最近观察到的窗口、预留量、替换范围与前后估算。面板只读，不能触发压缩或修改权限。
5. 通过正常插件管理为后续会话停用或移除插件。卸载会释放 UI 与 hook 注册；已提交元数据保留在会话账本中，遵循普通保留规则。

段落按 UTF-16 长度除以四、逐段向上取整估算。中英文都可能与供应商 tokenizer 相差很大。Surface 和压缩数值也来自 hook 估算。实际观察到的零显示为零，缺失值显示**未知**。规则/记忆的观察体积并不等于配置预算，现有 hook 不提供后者。后续贡献者可能尚未运行，因此不是最终模型请求归因。

大工具输出可能已转换为 artifact 引用。面板可计数结果节点和 Surface 估算，但不能推断原始字节、省略原因或实际保留的工具配对与固定节点。Core 继续负责配对和固定节点；面板不核验压缩后的保留结果。压缩前窗口属于该次观察，不一定是之后切换模型的窗口。当前模型窗口显示未知。

持久化仅保留固定分类与数值，不含提示词正文、路径、任意段落 ID/来源、工具名、模型名或凭据。查询使用经过认证的当前会话/分支，不接受会话选择参数，也不枚举其他会话或全局数据。projection 和响应上限 32 KiB，实时缓存最多 64 个快照。

若提示无法读取，请检查此会话是否包含后台行，再点“刷新”。缺失或旧版后台行不能自动提供其他会话的数据。重启、缓存淘汰或打开旧历史后，在新 hook 运行前显示未知；当前已安装插件的 hook reader 无法恢复自己的 projection。精确 wire/tokenizer 归因、历史诊断、卸载来源和保留核验等待后续授权只读诊断合同。

无需密钥的演示可运行[插件包](../../packages/package-manager/bundled-plugins/context-doctor/README.zh-CN.md)中的合成测试，覆盖中英文规则、记忆、大输出 Surface、模型窗口变化和压缩范围，不调用模型或外部效果。浏览器与真实模型验收留给集成检查。

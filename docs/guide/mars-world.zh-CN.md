# 火星基地：在 AGH 里指挥十一台设备

[English](mars-world.md) | 简体中文

[文档导航](../README.zh-CN.md) · [MHS 与设备接入](mhs.zh-CN.md) · [示例参考](../../examples/mars-world/README.md)

[`examples/mars-world`](../../examples/mars-world/README.md) 是一个火星上的小型科研基地，在浏览器里以 3D 呈现。基地里的十一台设备是虚拟的，但和真实设备一样说 MHS：它们连接 AgnesHub，声明自己的工具、状态和相机，被调用时会在世界里动起来。你在 AGH 里下达任务，大脑规划并驱动设备，你在一旁看着它完成。不需要任何硬件。

## 开始之前

- 一个[源码构建的 AGH](install.zh-CN.md)，并在 Web 里配置好模型。大脑要看相机画面、要调用工具，所以请选一个同时支持图片和工具调用的模型。
- 按[在 AGH 中使用设备](mhs.zh-CN.md#在-agh-中使用设备)的第 1–3 步装好 `@agnes/mhs` 插件。AgnesHub 会监听 `127.0.0.1:4180`。
- 一个支持 WebGL 和 WebCodecs 的桌面浏览器（较新的 Chrome、Edge 或 Safari）。

## 启动

1. 如果还没运行，带上 AgnesHub 的地址启动 Web，并启用插件：

   ```sh
   AGNES_HUB_ORIGIN=http://127.0.0.1:4180 node packages/cli/dist/local/agnes.mjs serve
   ```

2. 在另一个终端里，从仓库根目录启动世界。第一次运行会下载约 50 MB 的模型和贴图，并校验哈希：

   ```sh
   pnpm --filter @agnes/mars-world dev
   ```

3. 打开 `http://127.0.0.1:4200/?hub=ws://127.0.0.1:4180`。设备就运行在这个页面里，并从这里连接 AgnesHub。玩的时候保持页面打开，放到后台也照常运行。只开一个：再开一个页面会把同样的设备接管过去。
4. 在工作台右侧打开设备面板。Devices 标签里会出现十一台设备，World 标签显示基地地图和每台设备的位置。

`pnpm --filter @agnes/mars-world start` 是不接 AGH 的玩法：它在 `127.0.0.1:4180` 启动一个带命令行的 hub，并打开世界。AGH 的 AgnesHub 运行时不要用它，两者都要占用 4180 端口。

## 基地里有什么

| 设备 | 能做什么 |
| --- | --- |
| `rover-01` | 火星车：行驶、沿路线走、采集岩石样本、回坞充电。遇到巨石和人会自己停下 |
| `hopper-01` | 火箭飞行器：起飞、飞行、从空中勘察一片区域，并为火星车规划路线。受推进剂限制 |
| `monolith-01` | 由四块金属板组成的步行机器人：走路或滚动、跟随、抱起宇航员或样本、说话。`humor` 和 `honesty` 可以调 |
| `suit-01` | 在西边野外岩石露头处工作的宇航员穿着的宇航服。报告氧气、生命体征和头盔相机画面 |
| `airlock-01`、`habitat-01` | 气闸负责人员进出的加压和减压；栖息舱报告舱内空气并切换模式 |
| `lab-01` | 从停靠的火星车上卸下样本并分析 |
| `comms-01` | 转动天线，在通信窗口打开时向地球发送报告 |
| `power-01`、`weather-01`、`cam-base` | 电池组和太阳能阵列、气象站，以及俯瞰基地的相机 |

栖息舱声明了基地地图和带名字的地点（气闸、火星车坞、飞行器停机坪、实验室、岩石露头、西边野外等），所以下任务时可以直接说地名，不用给坐标。[示例参考](../../examples/mars-world/README.md)列出了每个工具、状态字段和数据源。

## 试试这些任务

在对话里输入，中英文或你的模型能处理的其他语言都可以。先从短的开始。

**看看情况**

> 基地现在怎么样？看看栖息舱的空气、电力和天气。

> 基地相机现在看到了什么？

**一台设备**

> 让火星车开到气闸门口。

> 把 Monolith 的幽默度调到 100%，让它跟大家打个招呼。

**多台设备协作**

> 野外的宇航员失联了，先派飞行器去西边野外找到宇航员，再让 Monolith 把宇航员接回栖息舱。

大脑会派飞行器出去勘察，让 Monolith 走到宇航员身边，给气闸减压开门，让 Monolith 把宇航员抱进气闸舱，再加压送进栖息舱。如果有别的设备挡路，它会先把那台设备挪开。

> 从空中找找西边野外有没有奇怪的岩石，让火星车沿飞行器给的路线去采样，送到实验室分析，再把结果发回地球。

火星车不能直接开到那块岩石，中间隔着岩石露头，飞行器给的路线会绕过去。天线只能在对地通信窗口打开时发送：世界页面打开后的前两分钟关闭，之后每四分钟里开三分钟。大脑会等窗口打开。

> 沙尘暴要来了，让基地做好准备。

这一题没有唯一答案：气象站、太阳能阵列、飞行器、火星车和气闸都各有要做的事。

## 观察过程

- **对话里**：每次设备调用都显示成一张卡片，带参数、进度和结果。
- **设备面板里**：Activity 按时间倒序列出大脑在本次对话里的设备调用；World 显示设备在基地地图上移动；单台设备的页面显示它的状态、数据和相机画面。在设备页面上按停止，或者让大脑用 `stop_device`，设备会立刻停下。
- **世界页面里**：按 `1`–`9` 切换固定视角（总览、火星车坞和实验室、飞行器停机坪、气闸、野外作业点、电力、旗帜、通信，以及跟随飞行器的视角），`0` 跟随 Monolith，`M` 开关小地图，`L` 开关设备标签。

## 重来一次

在世界页面右下角按 **Reset**，或按 `R` 键。所有正在进行的调用都会像被停止一样结束，设备回到起始位置：电量、推进剂和氧气加满，岩石恢复完整，气闸关好。设备保持连接，可以马上下达下一个任务。同时新开一个对话，免得大脑按上一轮的情况来规划。

## 遇到问题

| 现象 | 检查什么 |
| --- | --- |
| 面板里没有设备 | 世界页面是否打开、地址里是否带 `?hub=ws://127.0.0.1:4180`？插件是否已启用？4180 端口只能被一个程序占用：`mars-world start` 和 AGH 的 AgnesHub 不能同时运行 |
| 面板连不上 AgnesHub | 启动 Web 时没有带 `AGNES_HUB_ORIGIN=http://127.0.0.1:4180` |
| 某台设备反复掉线又上线 | 世界在两个页面里打开了，关掉一个 |
| 世界运行很卡 | 在世界页面地址后面加上 `&quality=low` |

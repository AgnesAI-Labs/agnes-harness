# 火星救援：11 台模拟设备

[English](mars-world.md) | 简体中文

[文档](../README.zh-CN.md) · [MHS 设备](mhs.zh-CN.md) · [示例源码](../../examples/mhs/mars-rescue/README.zh-CN.md)

新版火星救援包含 11 台模拟设备、MHS 页内 3D 场景，以及救援/采样业务 Agent 启动声明。设备使用 MHS SDK，不经 MCP。这是新产品示例，不迁移旧火星世界的数据。

已实现安装后的 profile 运行时与经审核的 producer 连接。启用本地示例会启动 profile 持有的模拟器，11 台设备完成真实 Hub 注册后才显示 Ready。缺少或撤销 child/parent 授权时拒绝连接。GPU、真实模型及完整浏览器流程仍须集成验收。

在已集成的 Host 中，进入 **MHS → 示例**，审核并启用本地包，然后等待 Ready；失败后可用 Start/Retry 重试。选择已配置且支持图片和工具的模型。程序化资源和许可完整随包，首次打开无需下载模型/纹理。`exampleOf` 不授予父服务权限，设备连接仍须显式审核，运动仍需 MHS 原生批准。

**1–9 / 0** 切换视角，**L** 切换标签，**M** 切换地图。离开场景或收起会话工作台不停止 profile 设备和模型相机。Stop 只断开本示例设备；Reset 中断调用、恢复模拟状态并保留注册。关闭浏览器、传输中断、挂起或撤权会停车断开；重新连接不恢复旧运动。

救援任务需定位宇航员、搬到气闸、准备基地并在安全循环后核对装备的救援状态。采样任务需巡查、按安全路线行驶、采集、停靠、分析并发送合成结果。业务 Skill 要求核对回执和状态，拒绝重放结果未知的动作。七工具和会话工作台由父 MHS 拥有。

设备、SDK 端口、本地检查、资源许可和集成限制见[包说明](../../examples/mhs/mars-rescue/README.zh-CN.md)。旧版外部模型场景及视频未随包分发，集成后可审阅的预览仍是验收要求。

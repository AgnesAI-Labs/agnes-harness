# 查看会话用量

[English](usage-cockpit.md) | 简体中文

[文档](../README.zh-CN.md) · [插件生命周期](packages.zh-CN.md) · [会话](sessions.zh-CN.md)

从内置插件目录安装 **Usage cockpit**（`@agnes/usage-cockpit`），审阅源码和 UI 能力，
信任并启用。它是默认关闭的可选插件，不向会话提示词增加工具。

1. 在侧栏选择可读取的会话，然后打开主页导航的“用量”，或该会话工作台的“用量”面板。
2. “会话”视图展示输入、输出、缓存 token、已记录美元和额度。额度不换算为美元。
   记录不完整时明确提示覆盖缺失；缺少用量或计费表示未知，不表示免费。
3. 使用支持键盘的双选控件切换到“调用”，查看主模型、摘要、审查、旁路调用、
   父会话记录的子任务和其他费用。供应商报告与估算美元分开显示，中断调用的费用保留。
4. 新活动发生或读取失败后点击“刷新用量”。旧投影不可用时显示可理解的重试状态。
   切换会话会丢弃旧会话尚未返回的读取。停用或卸载插件会撤销其 UI 注册。

会话总额使用后端账本投影，包含 effect/请求去重、供应商累计用量和费用调整。
调用明细按轮次调用的 effect ID 去重，可关联的正负调整应用到原费用，不重复统计 token。
这些金额已包含在会话总额中。轮次调用投影之外的记录、无法关联的调整和缺失请求用量的归属保持未知。模型切换可在单次调用记录中看到。
重启后端或重新打开面板时，从同一账本截点重新计算，不使用私有计费数据库。

覆盖提示始终可见：不读取独立子会话，包括未接管或其他所有者的子会话。
父会话已记录的子任务费用已计入一次。本页只展示选中会话，不是完整任务树账单。
Headless 父会话汇总同样不包含独立子会话账本。未来完整任务树视图需要对每个子会话
检查权限的授权聚合 API。插件不执行全局扫描、遥测上传、额度修改或预算覆盖。
金额是已记录证据或估算，不代表供应商最终账单。

离线演示可运行[包 README](../../packages/package-manager/bundled-plugins/usage-cockpit/README.zh-CN.md)
中说明的合成数据单测。查看已有记录不需要模型账户或 API key。

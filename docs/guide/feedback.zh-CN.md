# 反馈与人工评审的 Skill 成长

[English](feedback.md) | 简体中文

对已结束的助手消息点击**赞**或**踩**图标。桌面端在悬停或键盘聚焦时显示消息反馈按钮，触屏宽度始终显示；提示文字和无障碍标签说明各按钮的用途。展开**反馈备注**可填写可选分类与备注，然后保存。整个会话的评价在工作台的**会话反馈**面板填写。本人可以编辑或撤回；撤回保留之前的账本事实，也不会删除已评审的 Skill。

反馈仅保存在当前安装中，排除在可观测性上传之外，不进入普通模型历史，也不授权上传日志。原生会话导出包含反馈修订与成长关联，遵循导出的隐私脱敏规则。撤回写入撤回标记，不物理擦除历史。

对负面评价，或分类为**以后继续这样做**的正面评价，点击**生成改进建议**。先保存尚未提交的备注修改。此操作独立于正常回合，仅将反馈与已结束回合的消息、工具证据交给会话配置的本地模型，且有超时和大小限制。官方服务只允许 `127.0.0.1` 或 `[::1]` 上的 HTTP(S) 模型端点；远端模型在推理前被拒绝。生成前请先配置本地模型。

模型起草一个新的 Skill 包，不能通过此操作执行工具、修改记忆或发布插件。平台围绕草稿文本构造固定的注册代码和注册测试。到**设置 → 插件 → 候选**检查全部文件，显式执行候选测试，将该确切内容哈希提交评审，再批准或拒绝。批准使用现有候选流程发布评审快照；单独生成不会安装、信任、启用或应用建议。候选测试会执行候选代码，沿用现有确认步骤。

点击消息旁的**执行依据**，查看反馈版本、回合与消息引用、候选、评审决定和发布版本。评审后可刷新来源链。候选证据缺失或来源不匹配时显示不可用，反馈本身仍可读取。候选内容被修改时，按[候选合同](../extend/agent-built-plugins.zh-CN.md)撤销原有测试与评审。

**设置 → 反馈**列出当前已认证本地管理员拥有的会话反馈，包括未打开的历史会话。支持会话 ID、分类、赞踩、是否关联候选的筛选。统计对应筛选后的条目：赞踩排除已撤回项，撤回与候选计数包含保留的撤回记录。视图最多读取 256 个会话、4096 个当前条目或成长关联；聚合读取不完整时标记。单会话证据过大则拒绝读取。编辑或生成之前须重新打开保存的会话。

可替换公共服务见[反馈服务](../extend/feedback.zh-CN.md)。学习记忆仍遵循独立的[记忆审批策略](memory.zh-CN.md)。

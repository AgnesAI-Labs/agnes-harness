# 内置浏览器

[English](browser.md) | 简体中文

[文档](../README.zh-CN.md) · [Web 工作台](web.zh-CN.md) · [安全](security.zh-CN.md)

官方 `@agnes/browser` 插件让 AGH 与工作台使用同一个网页。后端运行专用浏览器，工作台显示它的实时画面。每个会话的 Cookie 和页面存储独立，不会通过另一个 iframe 再加载一份网站。

切换浏览器标签时复用面板的画面连接，只采集当前选中的页面，并丢弃切换期间迟到的旧页面画面。切换请求绑定当前已认证用户和会话，不授予输入控制权，也不提高底层连接限额。

工作台的展开状态只在同一会话刷新时恢复。新建或切换到另一个会话不会继承之前打开的浏览器面板；面板宽度和标签偏好仍保留。

## 开启与访问

在 **插件** 页面使用 **内置浏览器** 这一项的开关。插件在权限上限允许时默认启用，由用户自己打开工作台的浏览器标签；插件启动、切换会话或 AGH 打开网页都不会自动展开或切换面板。不再有独立设置开关。首次启用会自动将固定版本的浏览器下载到操作系统用户缓存，核对完整大小和 SHA-256 后准备运行；准备状态和错误显示在浏览器面板。失败后可在插件页关闭再开启重试。已有版本保存的独立关闭设置不再生效；插件页明确关闭的状态会保留，重启不会自动开启。

浏览器安装器依赖缺失时，准备失败且浏览器不可用；其他插件和新建会话仍可使用。修复安装后再重试准备。

在工作台的浏览器面板输入完整的 `http://`、`https://` 地址、工作区文件路径或 `file://` 地址，或直接让 AGH 打开。测试本地项目时，让 AGH 先用已有 shell 或 Jobs 工具启动项目，读取实际端口，再访问、检查和测试页面。Localhost 指的是后端所在电脑。关闭浏览器不会停止项目 Jobs。

AGH 可以查看当前元素、点击、填写、发送按键、滚动、导航、等待文字、截图、读取最近控制台及网络错误、关闭标签页。用户选中的标签保持不变，AGH 可在其他标签后台测试，不会弹出桌面窗口或自动展开面板；人工接管时保持该页可见，手动切换标签页会结束当前输入连接。最多同时容纳两个会话的浏览器上下文，每个会话最多三个标签页；达到上限时，可点击标签上的关闭按钮或让 AGH 关闭不用的标签页。关闭最后一个标签页会释放该会话的浏览器名额。

## 人工接管

直接点击网页中的输入框后即可打字，支持中文输入、macOS Option 字符、Windows AltGr 字符和粘贴。打开面板时预先准备经过原生会话授权的交互连接，但不接管网页。首次点击、滚动或导航通过该连接接管页面后再发送输入；也可主动点击 **接管**。等待审批或接管失败时不会转发待处理操作；接管期间若文档发生变化，原点击会被丢弃。Escape 将焦点返回工作台的浏览器控制按钮。点击 **交还 AGH** 结束人工控制；AGH 需要重新观察当前页面后才能继续写操作。

面板使用标签页和一条地址栏，在地址栏按回车访问当前标签页的新地址。标签显示域名和路径。**浏览器选项** 收纳重连画面与最近页面错误。文字由画面内不可见的焦点控件接收，不再显示独立编辑框。

网页四周保留窄留白和细边框，默认使用固定的 1280×800 桌面窗口，按面板可用宽高等比例完整显示。在 **浏览器选项** 可切换 **页面随面板自适应**，让响应式网页随可用空间重新排版，拖动尺寸时合并更新。关闭面板后保留最后的窗口尺寸，后台新标签默认使用 1280×800。**按 100% 显示** 使用固定窗口，可滚动查看原尺寸画面。多个窗口查看同一网页时，由首先申请尺寸的可见面板决定窗口大小，其他面板缩放同一画面，不互相争抢尺寸。窗口尺寸改变后，旧坐标和模型观察会失效，必须基于新画面操作。

实时画面使用双倍像素，文字页面滚动时优先无损 PNG；复杂画面根据图片大小调整 JPEG 压缩，保留双倍像素和画质下限，轻量画面恢复后重新使用无损格式。动态画面以最高 60 帧/秒为目标，静止后优先补充高清无损画面，沿用现有传输限额。实际帧率和延迟取决于页面、硬件与网络。鼠标坐标始终按当前网页尺寸换算；AGH 的截图仍按网页尺寸输出。Windows 滚轮按行或按页的输入与 Mac 触控板的小数像素输入都转换为页面滚动，并按执行回执合并相邻同方向滚动，避免指令积压；反向滚动、点击和按键保持顺序，切页、调整窗口、拒绝或断线时不重放旧滚动。

连接正常时，浏览器状态与当前会话的页面列表由已授权的流推送，不再定时查询；断线后有限次尝试重连，并通过原有校验入口查询兜底。画面的最后一次重连会等待一分钟，让准入限流窗口结束；不会自动重放输入操作。过长的网址也保留完整查询回退。最近页面错误仅在展开后刷新。打开网页成功后会直接显示结果，不等待额外的状态查询。刷新、前进和后退等待文档加载到可用阶段，不要求所有图片等资源加载完毕。

关闭面板会停止画面、页面订阅和恢复查询；重新打开时连接已有页面，不会重新导航、提交或重放输入。

状态读取暂时失败时，会显示错误并保留本会话的最后页面。实际输入仍需要有效的授权连接；切换会话会清空旧页面。

人工控制经过已认证的会话 effect。短输入租约可在五分钟内续期，到期后需要再次明确接管。输入连接中断会暂停控制，刷新工作台不会从历史记录恢复控制权限。访问受保护地址等明确拒绝会显示原因，允许改正后继续操作。只有请求结果不明时才显示 **核对上次操作**，沿用原请求编号读取已记录的结果；它不能自动确认仍然未知的实际操作结果。网站提交结果不明时，应先核实，不能换到另一个浏览器重复提交。

## 关闭、回退与产物

关闭插件开关会拒绝新操作、撤销输入、断开画面并关闭插件自己的页面。已经送达网站的操作无法撤销。清理结果不能确认时，浏览器保持不可用，直到完成清理核对。

模型根据任务、可用性与权限自主选择工具，用户明确指定的浏览器或工具优先；指定工具不可用时会说明，不会静默替换。内置浏览器可用于后台项目测试，不会自行开启已关闭的插件。插件不会自动开启 Computer Use 权限，也不会与桌面浏览器共享 Cookie。

生成文件不会自动打开面板。只有点击不超过 1 MiB 的可预览产物时，才打开已有的 Markdown、HTML、PNG/JPEG、PDF 或文本安全预览；不支持的格式和较大文件点击后下载，不展开预览面板。Office 演示文稿沿用已有下载流程，在 Office 或 WPS 中打开。本插件不新增 Office 或电子表格渲染器。安装或更新插件之前固定了旧版本的会话，可能需要执行已有迁移操作或新建会话。

## 兼容性与边界

已登记并核验 Windows x64、macOS Apple Silicon、macOS Intel 的浏览器安装包。只有在两个 Mac 架构上完成真机验收后，才能称对应发布版本已测试。Windows ARM64 和 Linux 暂无此插件认可的安装包。系统要求遵循固定的 Playwright 1.63.0 及配套浏览器；准备阶段需要网络和足够容纳安装包及解压文件的磁盘空间。

专用浏览器开启 Chromium 沙箱，不使用个人浏览器配置，也不向 WebUI 暴露调试端口。不提供任意 JavaScript 执行、自选可执行文件、不受限的文件系统访问、自动下载或 Service Worker。仅在 PDF 文档中允许固定 Chromium 的内置 PDF 查看器及其内部静态资源。已知 AGH 管理地址与云元数据地址会被阻止。此插件用于可信的本地开发；网址路由规则不等于操作系统级网络沙箱。准确版本和许可见 [运行时来源](../../third-party/browser-runtime.md)。

## 工作区文件资源

文件预览支持固定 Chromium 能显示的内容类型，包括 HTML 及其 CSS、JS、图片和字体资源、SVG、图片、文本、JSON、XML、PDF，以及内核支持的媒体格式。不会转换 Office 文件。无法显示而触发下载的格式会明确报错。媒体解码受浏览器和平台能力影响。同源或允许 CORS 的 HTML 音视频声音复用已授权的画面通道；WebUI 只在本地交互后播放声音，切页、导航或断线时丢弃待播放音频。隐藏面板不转发声音，也不会采集桌面声音。

文本预览只检查有界的 UTF-8 前缀来补充编码提示，保留 BOM 和 HTML/CSS 中明确声明的编码。HTML 编码只识别真实 `meta` 属性中的声明，忽略注释、脚本和普通属性中的示例，不读取整个文件，也不转换文件字节。

默认预览根目录是所选文件的目录；模型可在 `open` 输入中设置工作区内的 `previewRoot`，以加载公共资源。每个资源和每个 256 KiB 读取窗口都重新经过当前文件权限检查。拒绝 `.env`、`.git`、`.ssh`、`.agh` 等私有路径和文件系统别名。大文件通过分段读取及 HTTP Range 传输，不整份放入内存。资源准入头只由所属浏览器标签注入，复制临时 localhost 地址不能获得读取权限。关闭标签、会话或插件会关闭相应监听器。

可选的 `ToolContext.sessionFiles` / `ServiceContext.sessionFiles` 只读端口为延迟资源请求重新取得工作区调用权限；普通 `fs` 仍只在当前调用内有效，不能保留。旧 Host 没有该端口时拒绝文件预览，现有 HTTP 页面不受影响。

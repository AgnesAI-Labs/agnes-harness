# Web 工作台：集中管理任务与扩展

[English](web.md) | 简体中文

[文档导航](../README.zh-CN.md) · [首次配置](quickstart.zh-CN.md)

Web 工作台把任务、历史和管理操作放在一个本地界面中。首次使用按[快速开始](quickstart.zh-CN.md)配置模型；本页带你理解一次任务的状态、日常管理和连接方式。

主 Web 监听在首次 Surface 挂载表查询后台运行时即可启动。挂载表首次查询成功前，未知 Surface 路径返回 HTTP 503 与重试提示；成功的空表表示没有挂载。后续查询失败保留最后成功表，刷新不重叠，关闭会等待在途查询及其连接清理。

顶栏用滑块胶囊切换「对话 / 轨迹」，轮次运行时「轨迹」旁显示活动点。小虫子按钮直接打开「报告问题」，最右侧图标切换工作台。「运行信息」位于侧栏每个会话的菜单中；同一菜单还提供「在访达中打开」（macOS）、「在资源管理器中打开」（Windows）或「打开文件夹」（Linux），名称取自 daemon 的平台事实。此操作只在 daemon 本机桌面打开该会话已绑定的工作区；远程连接、无桌面环境或目录缺失会显示错误提示。

临时错误显示在右上角通知区，六秒后自动消失，也可通过带无障碍标签的关闭按钮手动移除。恢复、审批和账号修复提示保留到问题解决。附件按钮在悬停和键盘聚焦时使用共享 Tooltip；附件失败按当前语言区分体积、像素、文件类型和无效数据。

Surface 挂载表通过持久本地连接接收生命周期失效通知和重连事件，再重新查询后台权威表；健康空闲时不轮询。读取失败保留最近成功的表并串行重试，关闭时取消连接并等待当前读取收尾。

## 启动与连接

```sh
node agnes.mjs serve
```

Web 监听本机回环地址。当前页面不接收或保存本地连接 token；服务按启动时固定的 Origin 与 Host 校验连接。`localhost` 与 `127.0.0.1` 不能随意互换。改端口时设置一致的来源：

```sh
export AGNES_WEB_ORIGIN=http://127.0.0.1:4180
node agnes.mjs serve --port 4180
```

若旧后台使用不同 Origin，新启动会拒绝复用；先确认任务状态并显式停止该实例，再启动。它不是远程公开站点部署入口，也没有本文承诺的反向代理登录方案。

页面的会话与审批通信通过浏览器 SDK 的 WebSocket 直连 daemon；资源/插件管理和插件后端服务使用同源 HTTP BFF。两者都是本地工作台的一部分，详见[通信架构](../develop/architecture.zh-CN.md#web-的两条通信路径)。

## 完成一轮任务

1. 从侧栏新建任务，在创建面板确认工作目录；取消面板不会创建会话。
2. 从模型选择器选当前会话使用的 route/model。Provider 默认配置和当前会话选择是不同操作。
3. 输入消息，点击发送或 Cmd/Ctrl+Enter；运行中继续发送会排队为 follow-up，当前轮正常完成后按顺序自动执行。停止、执行失败或等待审批时暂停自动继续，未执行的输入保留在队列中。停止或失败后发送新消息，会先按顺序执行保留的输入，再执行新消息。
4. 待执行消息显示在输入框上方，包含数量和顺序；重新打开或重连后也能恢复。点击某条消息的“立即发送”，会先停止当前轮，再优先执行选中的消息；其他消息保持原有顺序，在它正常完成后继续执行。点击“删除”只移除该条待执行消息，不会停止当前轮或启动排队任务，其他消息顺序保持不变。这是从执行队列中移除，原始事件仍保留在会话历史中。已开始执行的消息不能删除，也不会重复发送。操作失败时，错误显示在队列旁，并刷新列表。

5. 按工具记录阅读参数、结果及错误详情。思考文本、工具状态和用量来自后台投影；没有返回的内容不会凭空补全。
6. 需要审批时检查实时选项和授权范围。即使请求在已加载的历史窗口之外，审批卡也会读取当前审批并显示详情、可选操作和相对过期时间。加载失败时可点击“定位审批”重试并补载较早历史；找到后审批卡滚动到可见位置并获得键盘焦点。提交后等待后台确认，不用页面按钮是否消失判断工具已执行。
7. 点击“停止”后等待后台确认；已经结束或挂起的回合同样可以完成停止，不必再产生一个结束事件。超过 10 秒未确认或请求失败时，输入框恢复可编辑，并显示“重试停止 / 强制结束”。强制结束会通过独立的取消通道重发请求，再读取后台的停止记录；不能确认时仍明确提示，不把断开连接当成已停止。正在执行的回合会取消待决审批并中止工具；已经可能发生的工具副作用仍标为未知，不会自动重放。

侧栏按工作区文件夹归类会话，文件夹内新会话在前，正在运行的会话旁会显示一个圆点。点击文件夹可以折叠或展开，浏览器会记住这个选择。文件夹行上的加号在该工作区新建会话，「工作区」标题旁的文件夹按钮用来添加工作区。按 Shift+Cmd+O（Windows 和 Linux 为 Shift+Ctrl+O）可以新建会话。顶栏依次显示会话标题、所用 Agent 和运行信息按钮，右侧是「对话 / 轨迹」切换与工作台开关。

新会话首页的空输入框会轮流打出业务 Agent 目录中的示例任务。出现 **Tab 采用** 时，按 Tab 会填入草稿并把光标放到句末，不会发送任务。输入、粘贴或添加附件后暂停，只有输入框重新为空且失去焦点才恢复；其他情况下 Tab 正常切换焦点。启用减少动态效果时保留普通静态占位文字，不提供 Tab 采用。示例本身仍可从侧栏的**业务 Agent**页面进入。

桌面端收起侧栏后，会保留「新建会话、业务 Agent · FDE、插件、自动化、设置」图标栏。图标保持相同操作，鼠标悬停或键盘聚焦时显示名称，并标记当前页面。窄屏端收起侧栏则会隐藏整个抽屉。

对话区左缘的一列细横线是提问导航，每条对应你的一次提问，当前读到的那一轮颜色更深。未悬停时所有横线保持默认短线长度，鼠标进入导航后附近的横线才会放大，悬停可预览那次提问和回答的开头，点击跳到那次提问并短暂高亮。按 Option+↑ / Option+↓（Windows 和 Linux 为 Alt+↑ / Alt+↓）跳到上一个或下一个提问；窗口较窄或打开工作台使左侧没有空间时，横线隐藏，快捷键仍可用。预览卡右上角可以给这次提问加书签，书签跟着会话保存，对应横线前会显示一个小圆点。

新会话准备就绪后即可发送首条消息，侧栏刷新不会阻塞发送。侧栏刷新失败会单独提示，不会把已经提交的消息恢复成草稿。
启动期间发现的资源更新会在后端空闲时提前加载；运行中发现的更新仍在下一轮开始前加载。重复扫描 Skill 时，如果资源没有变化，就不会再次触发后端重载。

### 添加文件和图片

点击发送按钮旁的回形针，也可以粘贴或拖入文件。每条消息最多 50 个附件，包括空文件。普通文件按 1 MiB 顺序分块上传，输入框里的状态显示已确认字节数、百分比、校验阶段和取消按钮。读取或发送文件字节前会先检查大小和 MIME 限制。默认每个文件不超过 2 GiB；在 daemon 环境中设置 `AGH_UPLOAD_MAX_BYTES`（字节数）和 `AGH_UPLOAD_MIME_TYPES`（逗号分隔的 MIME 类型，空值不限制）即可配置。MIME 校验使用声明的元数据，不检查实际格式。失败分块最多自动尝试三次；工作进程仍存活时，“重试”沿用同一上传续传，并分块重算本地摘要。取消等待服务端确认清理；未确认时可以重试取消。中断的部分上传在空闲 30 分钟后、会话关闭或恢复时清理。刷新页面后需重新选择文件。

文字模型也能添加附件。当前模型支持图片时，PNG、JPEG 走图片输入，处理后合计不超过 100 MiB、800 万像素。图片先按 1456 像素长边和模型声明的更低尺寸限制缩小。浏览器能解码但严格校验不接受的 JPEG（例如带尾部附加数据的文件）会先重新编码；普通小图保留原样。内联图片仍校验规范 Base64、合计大小、结构和尺寸，并受 144 MiB WebSocket 帧上限约束。文件上传通过原始 HTTP 分块传输，消息里只保存引用，原始字节不占用该帧。

上传原件保存在授权工作区的 `.agnes-attachments/<session-hash>/<receipt-id>/<sha256>`。服务端验证完整 SHA-256 后返回 `agnes-upload://` 资源引用；会话消息保存引用和展示信息。文件名不会选择磁盘路径。移除输入框里已上传的卡片会取消该回执并删除原件；发送后清空输入框，保留原件供消息引用。已有 `read` 工具可用 `session-file://12/1` 读取 UTF-8 和带 BOM 的 UTF-16 文本，用 `session-file://list` 查找旧附件。上传读取只取有界的字节前缀，行分页无法超出此前缀；更大原件通过授权 shell 对工作区文件做范围读取。CSV、TSV 按实际文本内容读取，即使类型标为 Excel。文件名和读取内容作为不可信数据处理。会话附件查找检查所属会话（或 fork 继承边界）和分支；工作区访问仍遵守 sandbox 和私有根策略。

默认启用的 `@agnes/document-reader` 插件提供 `document_read`，读取 PDF、DOC、DOCX 和 ZIP。PDF 按指定页读取，没有文字的页面使用内置的离线中英文 OCR；文字层不完整时，用 `ocr: "always"` 强制识别，混合 PDF 逐页处理。Word 提取正文、表格和注释等文字，不还原排版或内嵌图片。ZIP 先列出文件名，再读取选定的文本或支持的文档，不解压到磁盘。不额外限制 ZIP 条目数量和合计展开大小；大成员不会挡住其他文件。选中文件解析仍共用 100 MiB 输入预算，长文字分页返回；OCR 像素、任务时间和并发数也有边界。不执行宏、链接或文档里的指令。禁用插件后停止解析，已上传文件仍保留。OCR 可能识别错；加密、损坏或不支持的文档会明确报错。

PDF 里的照片、图表和排版可以用 `mode: "image"` 按页看图，不运行 OCR，同时保留已有文字层。默认 `mode: "auto"` 在文字提取和 OCR 均无结果时也返回该页图片；`mode: "text"` 只返回文字。OCR 没识别到文字不等于空白页。页面图片沿用现有授权通道，并遵守所选模型的图片限制，历史图片也计入；最长边不超过 1456 像素，每张不超过 4 MiB，每次只渲染选定的一页。文字模型仍能读取提取出的文字，但要理解页面图片，需要可用的视觉通道；不会自动启用新的视觉服务。

当前安装的 pi-ai 聊天接口只有文字和图片输入，不接收原生文件、音频、视频内容块。二进制 Excel、演示文稿、音频、视频等尚不支持的格式仍可上传保存，但上传成功不等于模型已经读过。agent 必须如实说明读取失败的原因。GIF 等其他图片格式保留原始文件，避免悄悄只留下第一帧。

模型的 `inputLimits` 直接来自 pi-ai 模型目录；手动模型也可以声明同名字段。数量按当前模型声明的限制执行，不统一限制为 4 张。支持图片的 Agnes 模型每次完整请求最多 4 张，历史消息和工具返回的图片也计入。模型的图片字节上限按 Base64 编码长度计算，与上述 100 MiB 原始图片字节上限分别校验。处理后仍超限会拒绝添加，并保留已选附件；发送前还会重新检查整批图片。待发送消息共用一条队列记录，受 144 MiB 传输帧上限约束，并给包装预留 4 KiB。已能确定队列超过帧预算时，会在解码新媒体前拒绝；可接受的输入仍需通过格式校验和精确 UTF-8 帧大小校验才能保存。队列合计超限时会在保存前拒绝新消息；请等前面的消息处理完，或移除一条后重试。

附件可以单独发送，也可以与文字组合发送。任务运行时，新消息会作为 follow-up 排队。在文字模型下添加的图片会作为文件保存，不会提供视觉输入。切换模型保留草稿；原先按图片模型处理的图片仍需兼容模型才能发送。发送失败后，文字和附件会恢复，方便重试；切换会话时会清除尚未发送的附件。

长会话会保留记录里的原图。平常只在模型额度内发送最近三条带图用户消息中的图片；这是历史窗口，不是每次只能上传三张。新附件会整批发送，无法容纳时明确报错。模型主动调取旧图时，最近一次调取的整批图片优先于其他旧图和截图。没送入本次请求的图片会保留引用、已有文字说明，并提示不能猜测未看到的细节。压缩上下文时也使用这套限制，不额外调用模型生成图片摘要。

比较早期图片时，可以直接要求模型重新查看那些原图。已有的 `read` 工具可用 `session-image://list` 分页列出图片，再读取 `session-image://12/1` 这样的引用；整批读取使用 `session-image://12/1,34/2`。压缩上下文不会删除原图。每批调取都要符合模型和运行环境的图片限制；几十张图片应分批比较，需要同时看更多图片时选择支持相应数量的模型。

实际调用前会按执行模型再次检查本次选中的历史图片、当前图片及工具返回图片的数量与尺寸。切换模型不会自动删除草稿图片；不兼容时需换回支持的模型或移除图片。请求大小在 pi-ai 的供应商载荷回调中检查，支持 fetch 的通道还检查最终 HTTP 请求体；SDK 后续包装仍可能触发供应商限制。

图片和 ACP 内联附件仍保存在用户消息和会话事件中。ACP 内联文件使用 `file` 内容块和标准内嵌资源，并声明支持 `embeddedContext`；URI 仅作名称，不会据此下载或读取磁盘文件。Web 分块上传文件使用普通 `resource_link` 内容块，携带上述校验后的 `agnes-upload://` 身份。文件附件需配套客户端和后端。Web 历史投影读取预算为 144 MiB 减去给传输包装预留的 4 KiB，协议默认仍为 256 KiB。工作进程把超出一帧的历史拆为更小序号范围，保留顺序和完整页；重开会话会重建图片预览和文件卡片。较小读取预算的客户端可能无法恢复大的内联附件消息。`artifact.read` 不接收浏览器上传文件。诊断和默认导出隐藏编码附件数据；归档 ledger 时需另外保留上传的工作区原件。

打开输入框旁的模型选择器。把鼠标移到某个模型上，列表旁边就显示该模型的会话设置：模型容量、思考强度、上下文窗口。档位按该模型支持的能力显示。打开上下文窗口可以选预设，也可以填完整 Token 数量或带 `K`/`M` 单位：`100K` 表示 100,000 Token，`100` 只表示 100 Token，对普通模型过小，无法保存；留空可恢复自动。改完立即生效并收起菜单，手填的预算在按回车或离开输入框时提交。给非当前模型选值时，会先切换到那个模型。设置影响后续请求，重新打开会话也会保留。账户设置里的配置作为新会话默认值；默认值变化不会覆盖已有会话。

在“设置 → 外观”选择英文或简体中文。自动标题优先使用模型从首条消息中判断出的语言，例如在中文界面发送“Hi”，仍生成英文标题。无法判断时，包括混合语言没有明显主语言，或只有代码、标识符、数字、表情等内容时，模型使用提交该消息时传入的界面语言。这些语言规则通过提示词约束；输出只校验格式，不替换语言，也不额外调用模型。切换界面语言不会翻译已有标题，也不会覆盖手动命名。

失败回合会在状态下直接显示后台记录的错误码和原因，折叠过程也不会隐藏错误；重开会话后仍可查看。旧记录没有具体错误详情时会明确说明。

### 查看轨迹

从“对话”切换到“轨迹”，可按轮次和步骤查看会话。选择记录可查看状态、耗时、错误和可用的 token 用量。时间图提供四种顺序与耗时模式：拖选可筛选，滚轮可缩放，右键拖动可平移，按 Esc 可清除范围。

可折叠轮次和工具调用、搜索记录或加载更早历史。“投影内容”中的工具参数和结果是预览；选择“完整输入”或“完整输出”可按需读取已记录的详情。“时间”页显示已记录的时间字段。缺少的时间、用量或历史会明确标注，不作估算。

窄屏下从记录列表选择时间图中的事件，图表保留总览。选中详情会使用完整内容区；点击关闭详情或按 Escape 回到原记录。切回“对话”即可使用输入框。设置分类可横向滚动，输入框的选项芯片会换行，保持操作区域可用。

## 日常管理

设置中管理模型账号、插件、Skills/MCP、外观及 Computer Use；可用项受后台能力和权限约束。插件安装后还要信任与启用，见[插件管理](packages.zh-CN.md)。侧栏可以重新选择历史会话；归档的任务从对应归档入口查找，归档并不等于删除历史。

Computer Use 显示驱动状态、系统权限、诊断与维护进度。切换设置页时继续监控进度；面板替换或重新加载后读取最新操作，不重新提交。移除面板只停止本地监控；需要取消后台操作时，显式点击“取消操作”并等待确认。连接失败或等待时间较长不能证明操作已经完成或取消。

接入 MCP 时，可以在聊天中说明“帮我接入这个 MCP”并提供服务地址或连接信息，再到设置中查看详情；新建的服务需要依次信任和启用，详见[MCP 接入](mcp.zh-CN.md)。涉及凭据时使用 SecretRef 配置流程。

页面通过 URL 的 `session` 参数选择会话。会话打开后会清理一次性的示例启动参数，刷新恢复当前对话。刷新和短暂断线后，SDK 从后台重新读取投影，不自行重发业务请求。重新连接失败时先查看 `daemon status`；后台重启后用当前 `serve` 输出的普通地址打开。当前本地模式无需从 sessionStorage 恢复启动 token。

关闭浏览器、主动断开页面或结束 `serve` 只影响客户端/Web 服务。后台任务是否结束以会话事实为准。完全结束实验实例需要另行 `daemon stop`。

### 定时任务

「自动化」页列出定时任务。每个任务都要选在哪里运行：

- **新会话**（默认）：每次运行都在所选工作区开一个新会话，以任务名和开始时间命名，再在里面运行。还可以选执行方式或业务 Agent、权限预设和模型；不选的项与新会话的默认值相同。
- **现有会话**：到点把任务发到一个会话。会话空闲时开始一轮，正在运行时并入当前一轮。

频率可选一次、每隔若干分钟或小时、每天、每周或 Cron 表达式，默认用这台电脑的时区。保存前表单会显示下次运行时间。每一行显示运行位置、规则、下次运行、启用开关和上次结果；菜单里有立即运行、编辑和归档。运行记录逐条显示运行中、等待审批、已运行、已送达或失败，附耗时、失败原因和会话链接。运行遵守正常的审批策略：需要审批时和其他会话一样等待，运行记录会链接到它。电脑没开时错过的重复任务，只补最近一次。会话的运行信息里也会列出这个会话接收或创建的定时任务。

在对话里说「每天早上帮我整理……」这类重复的工作，会在当前工作区建一个新会话任务；「30 分钟后提醒我」「明早继续这个任务」这类一次性提醒发到当前会话。回复会说明任务在哪里运行。工具说明见[默认工具](../reference/default-tools.zh-CN.md)。

## 当前交互边界

内置右栏文档预览支持文本、代码、Markdown、经过过滤的 HTML，以及由会话资源服务提供的图片或 PDF。资源读取失败时显示通用的不可用提示；截图已被回收时显示保留策略清理提示。替换或关闭预览会释放其取得的资源 URL，并忽略迟到回复。关闭预览不会取消后台工作。工作台 CSP 允许图片和框架加载本地 Blob URL，仍拒绝远程来源，PDF 框架保留 sandbox。其他页面维持原有 CSP。部分浏览器不允许在 sandbox 框架中运行原生 PDF 查看器，这些浏览器无法显示内嵌 PDF 预览。

工具结果以受约束预览/详情呈现，不是任意 HTML。不要推定每种产物都支持上传、下载、重命名，或每条消息都有编辑/重新生成；界面只暴露当前后端支持的动作。真实浏览器全链路的验证范围见[验证记录](../maintainers/verification.zh-CN.md)。

## 终端与后台任务

打开会话，在工作台选择**终端**。引导卡使用上次选择的 Shell 新建终端（macOS 默认 zsh，Windows 默认 pwsh，其他平台默认 bash），旁边的箭头可选择其他 Shell。有页签时，点击 **+** 使用记住的 Shell；右键、长按或聚焦 **+** 后按 Shift+F10，可选择 Shell 或连接 Agent 的任务。

xterm.js 画面跟随应用主题，保留 ANSI/OSC 颜色，并随面板大小调整 PTY。聚焦画面后可以输入、粘贴（每次最多 64 KiB UTF-8）、使用方向键或 Ctrl+C。刷新会重新连接同一 PTY。双击用户终端的页签名称，或在菜单中选择**重命名**，可就地改名；Enter 或失焦保存，Escape 取消。名称按会话保存在当前浏览器。

右键页签或按 Shift+F10，可中断、查看会话／任务 ID／工作目录或终止用户终端。用户终端的 **×** 会结束运行中的进程并关闭页签；Agent 页签的 **×** 只取消跟随。关闭工作台只断开界面，进程仍运行。Agent 的任务只读。退出码显示在画面末尾，页签以灰点表示零、红点表示非零。输出截断和输入已满提示位于顶部，可关闭。输出采用有上限的快照：两次轮询间丢失的文本或保留尾部之前的内容无法恢复。

旧链接 `/?settings=terminal` 会打开可用会话工作台中的终端。如果没有打开会话，则关闭设置并提示先打开会话再使用终端。

设置中的后台任务页按会话标题、工作区名和相对时间选择会话，自动读取当前会话并持续更新。它显示 shell 命令、持久解释器、PTY 和子代理的状态与输出。人类拥有的运行中任务可通过行菜单终止，并须再次确认；Agent 所属任务只能查看，请在会话中要求 Agent 停止。所有操作遵守所属会话的沙箱预设。

`agnes/jobs-web` 扩展需要 capability ceiling 的 `services`。新模板已包含；旧配置可显式添加。未添加时 shell/作业工具继续可用，Web 控制不可用。任务可跨页面刷新和轮次保留，Host 重启后不会恢复。本地 PTY 支持 macOS/Linux；缺少 shell 或不支持交互执行的提供方会明确报错。

已保存的网页搜索服务可以处于就绪状态而尚未设为默认。搜索设置在就绪服务旁显示「用作默认服务」，并说明选定默认服务后才能测试。配置抽屉同时提供启用和默认控件；保存失败时保留原有搜索状态。

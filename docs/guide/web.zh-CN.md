# Web 工作台：集中管理任务与扩展

[English](web.md) | 简体中文

[文档导航](../README.zh-CN.md) · [首次配置](quickstart.zh-CN.md)

Web 工作台把任务、历史和管理操作放在一个本地界面中。首次使用按[快速开始](quickstart.zh-CN.md)配置模型；本页带你理解一次任务的状态、日常管理和连接方式。

[内置浏览器](browser.zh-CN.md)插件提供可开关的实时浏览器面板，用于网页任务与本地项目测试。AGH 和面板操作同一个后端页面，保留会话隔离与明确的人工接管。

主 Web 监听在首次 Surface 挂载表查询后台运行时即可启动。挂载表首次查询成功前，未知 Surface 路径返回 HTTP 503 与重试提示；成功的空表表示没有挂载。后续查询失败保留最后成功表，刷新不重叠，关闭会等待在途查询及其连接清理。

顶栏用滑块胶囊切换「对话 / 轨迹」，轮次运行时「轨迹」旁显示活动点。小虫子按钮直接打开「报告问题」，最右侧图标切换工作台。「运行信息」位于侧栏每个会话的菜单中；同一菜单还提供「在访达中打开」（macOS）、「在资源管理器中打开」（Windows）或「在文件管理器中打开」（Linux），名称取自 daemon 的平台事实。此操作只在 daemon 本机桌面打开该会话已绑定的工作区；远程连接、无桌面环境或目录缺失会显示错误提示。

临时错误显示在右上角通知区，六秒后自动消失，也可通过带无障碍标签的关闭按钮手动移除。恢复、审批和账号修复提示保留到问题解决。存储为 artifact 引用的附件在历史消息中保留文件标签，内部 URI 不直接用作下载链接。附件按钮在悬停和键盘聚焦时使用共享 Tooltip；附件失败按当前语言区分体积、像素、文件类型和无效数据。

应用页面或工作台操作发起全局审批时，发起操作的浏览器会立即在当前页面上方打开确认对话框。允许一次或拒绝前，请核对插件、操作、业务对象、修订和本地格式的到期时间。关闭对话框或离开发起页面后，请求仍保留为待处理。确认不会自动派发业务操作，请通过原页面已有的操作回执继续。

侧栏仅为剩余全局审批及需要处理的自动化运行显示带数量徽标的「待处理」入口，无需选中会话。点击后打开独立对话框，按定时任务、触发器和插件请求分组。自动化事项打开对应运行会话；插件请求可在对话框中允许一次或拒绝。其他客户端产生的通知不会自动打开确认框。缺失操作标题时显示本地化通用说明，技术标识收在技术详情中。审批变更推送、页面聚焦、返回可见标签页和重连时刷新，不周期轮询。

Surface 挂载表通过持久本地连接接收生命周期失效通知和重连事件，再重新查询后台权威表；健康空闲时不轮询。读取失败保留最近成功的表并串行重试，关闭时取消连接并等待当前读取收尾。

项目行在悬停或键盘聚焦时显示「新建会话」和「…」。新建会话沿用现有创建流程并预选该项目的文件夹，
已注册且可用的目录会跳过文件夹选择。项目菜单还可以在本机文件管理器中打开目录，或选择「移除项目…」。
确认移除后，该项目的会话进入「已归档」，磁盘文件全部保留；有运行中的会话时须先停止。
重新添加同一文件夹会恢复项目列表项，会话仍保持归档，可以逐个恢复。

智能体页推广 showcase 产品应用；旗舰包尚未提供时不显示占位，也不改推教学包。新会话提示词使用相同的推荐来源。[五个开发者教学示例](../../examples/fde/README.zh-CN.md)保留在插件目录，显式安装后可从智能体页使用。

## 启动与连接

```sh
node agnes.mjs serve
```

Web 监听本机回环地址，无需登录：直接打开 `serve` 打印的普通地址。服务按启动时固定的地址校验 Host 与 Origin，其他网站的网页无法驱动它；同端口的 `localhost` 地址会被重定向到 `127.0.0.1`。改端口时设置一致的来源：

```sh
export AGNES_WEB_ORIGIN=http://127.0.0.1:4180
node agnes.mjs serve --port 4180
```

若旧后台使用不同 Origin，新启动会拒绝复用；先确认任务状态并显式停止该实例，再启动。它不是远程公开站点部署入口，也没有本文承诺的反向代理登录方案。

页面的会话与审批通信通过浏览器 SDK 的 WebSocket 直连 daemon；资源/插件管理和插件后端服务使用同源 HTTP BFF。两者都是本地工作台的一部分，详见[通信架构](../develop/architecture.zh-CN.md#web-的两条通信路径)。

## 完成一轮任务

1. 从侧栏新建任务，在创建面板确认工作目录；取消面板不会创建会话。
2. 从模型选择器选当前会话使用的 route/model。Provider 默认配置和当前会话选择是不同操作。
3. 输入消息，点击发送或 Cmd/Ctrl+Enter；运行中继续发送会排队为 follow-up，当前轮正常完成后按顺序自动执行。停止、执行失败或等待审批时暂停自动继续，未执行的输入保留在队列中。停止或失败后发送新消息，会先按顺序执行保留的输入，再执行新消息。
4. 待执行消息显示在输入框上方，包含数量和顺序；重新打开或重连后也能恢复。点击某条消息的“立即发送”，会先停止当前轮，再优先执行选中的消息；其他消息保持原有顺序，在它正常完成后继续执行。点击“删除”只移除该条待执行消息，不会停止当前轮或启动排队任务，其他消息顺序保持不变。这是从执行队列中移除，原始事件仍保留在会话历史中。已开始执行的消息不能删除，也不会重复发送。操作失败时，错误显示在队列旁，并刷新列表。

5. 按工具记录阅读参数、结果及错误详情。思考文本、工具状态和用量来自后台投影；没有返回的内容不会凭空补全。重试只出现在最新的失败回合上；历史账本完整性错误或 hook 阻止不提供重试。
6. 需要审批时检查实时选项和授权范围。即使请求在已加载的历史窗口之外，审批卡也会读取当前审批并显示详情、可选操作和相对过期时间。加载失败时可点击“定位审批”重试并补载较早历史；找到后审批卡滚动到可见位置并获得键盘焦点。审批卡标题下用纯文本写明是谁在请求（包、角色、MCP 服务），选项下方列出「本会话允许」会保存的 scope（最多三个，其余悬停查看）。持久化的审批卡上可点“附理由拒绝”，弹出单行输入框（最多 500 字符，回车拒绝，Esc 返回），模型会读到这条理由；理由为空等同普通拒绝，实时提示没有这个输入框。提交后等待后台确认，不用页面按钮是否消失判断工具已执行。

   AGH 配置和指令文件的逐次审批适用于声明写入路径的工具。shell 不声明目标：全权限下的 `echo ... > AGENTS.md` 不受此规则约束。强隔离由沙箱负责（[安全说明](security.zh-CN.md#审批)）。
7. 点击“停止”后等待后台确认；已经结束或挂起的回合同样可以完成停止，不必再产生一个结束事件。超过 10 秒未确认或请求失败时，输入框恢复可编辑，并显示“重试停止 / 强制结束”。强制结束会通过独立的取消通道重发请求，再读取后台的停止记录；不能确认时仍明确提示，不把断开连接当成已停止。正在执行的回合会取消待决审批并中止工具；已经可能发生的工具副作用仍标为未知，不会自动重放。

侧栏按固定顺序分为三个分区：**置顶**、**项目**、**临时会话**。点分区标题可以展开或收起，浏览器会记住哪些分区已收起；分区本身不能调整顺序。**项目** 分区里按项目分组，以最近一条可见消息的时间排序，空会话使用创建时间；项目可以拖动，或在项目行上按 Alt+↑/↓ 移动，**视图选项 → 重置顺序** 恢复默认顺序。首次只展开最新的非空项目并加载五条会话；“显示更多”每次再加载五条，“收起”回到前五条。关闭项目会释放已加载列表，这一展开状态只在当前页面保留。当前会话即使不在已加载的列表里，也可以继续阅读。行尾在运行时显示转圈，等待你处理时显示 **待审批** 或 **待回答**，否则显示最近一次变化的时间；标题前的小圆点表示你离开期间完成的一轮，打开会话后消失。

分组加载完成后，后台更新保留已有列表和分页控件，不再反复显示加载文字。等待摘要和页面刷新期间，分页控件暂时禁用，完成后使用新游标。窗口聚焦与页面恢复可见触发的重叠刷新共用一次读取。未变化的首页会直接复用；切回窗口、重连或手动重试时，也会核对会话改名等信息。首次加载和失败仍显示状态；只有刷新停止且数据仍过期时才提示重新加载。

加载多页后，如果该组内容变化，会提示重新加载，避免拼接不同版本的分页。历史消息摘要在后台初始化，失败时可以重试。启动时读取失败或尚未就绪，不会被当作没有历史会话而自动进入新建或首次引导；重试恢复列表后，可以选择会话，期间已有的手动选择会保留。归档和无权访问的会话先过滤再分页；搜索独立于侧栏已加载的内容。项目行上的撰写按钮在该项目里新建会话。**项目** 标题上有 **视图选项**（分组方式、归档筛选、重置顺序）和 **打开项目文件夹**；列表上方的 **搜索会话**（Cmd+K，Windows 和 Linux 为 Ctrl+K）打开会话搜索。按 Shift+Cmd+O（Windows 和 Linux 为 Shift+Ctrl+O）可以新建会话。顶栏依次显示会话标题、所用 Agent 和运行信息按钮，右侧是「对话 / 轨迹」切换与工作台开关。

新对话时，输入框下的工作区标签打开可搜索的工作区列表，**新建工作区…** 打开完整对话框添加工作区。点标签上的 **×**（不在工作区中工作）改为开临时会话。所有临时会话共用 Agnes 数据目录下的同一个文件夹，彼此能看到对方写入的文件；权限、沙箱和 hooks 信任与普通工作区相同。侧栏把它们归在 **临时会话** 组，这一组不能移除，也不能在文件管理器中打开。从已打开的临时会话新建对话，默认仍是临时会话。

新会话首页的空输入框会轮流打出智能体目录中的示例任务。出现 **Tab 采用** 时，按 Tab 会填入草稿并把光标放到句末，不会发送任务。输入、粘贴或添加附件后暂停，只有输入框重新为空且失去焦点才恢复；其他情况下 Tab 正常切换焦点。启用减少动态效果时保留普通静态占位文字，不提供 Tab 采用。示例本身仍可从侧栏的**智能体**页面进入。

侧栏依次列出 **新对话、插件、智能体、自动化**，随后是工作区和对话历史，官方界面底部仅保留 **设置**，应用可从 **智能体** 和 **设置 → 应用** 进入。采用应用后，宿主提供的 **返回官方界面** 和 **切换应用** 入口始终保留。智能体来自插件显式声明的启动信息；内置 **通用助手** 可以直接选择 **运行方式**。插件页采用单列表，按 **来源** 与 **能力** 筛选，另有 **技能**、**连接（MCP）** 页签，主列表说明用途和当前状态，登记信息收在技术详情中。设置分组为 **通用 / 模型 / 权限 / 应用 / 高级**；**模型 → 运行配置** 保留执行配置，原全局叠加页改名为 **所有对话附加组合**。应用设置提供预览、采纳和清除操作。智能体页面按当前生效应用的可见列表展示，默认智能体优先；已有会话的执行绑定保持不变。

**设置 → 应用**在当前设置页内预览应用与界面实现；采纳前可检查身份、可见变化、智能体和权限。官方侧栏底部打开 **设置**，应用恢复也可从此处和智能体页进入。**设置 → 通用**分别提供配色、皮肤、字号和语言；皮肤与语言使用支持键盘操作的选择器，配色可选跟随系统、浅色或深色。已保存的皮肤选择在插件暂不可用时仍保留，期间回落宿主外观，皮肤重新可用后恢复。

在 **设置 → 应用 → 高级界面选择** 中，可从受信且启用的插件预览并选择导航、对话、输入框、目标、交互或交付物实现。每行标明 **默认 / 应用 / 你的选择**。“恢复默认”仅清除单个角色覆盖。不可用的选择保留为 unresolved，并回落到应用或宿主。`/?admin` 和 `agh app clear` 同时清除应用及全部界面实现选择，执行配置保持不变。

桌面端收起侧栏后，会保留「新对话、插件、智能体、自动化、设置」图标栏。图标保持相同操作，鼠标悬停或键盘聚焦时显示名称，并标记当前页面。窄屏端收起侧栏则会隐藏整个抽屉。

对话区左缘的一列细横线是提问导航，每条对应你的一次提问，当前读到的那一轮颜色更深。未悬停时所有横线保持默认短线长度，鼠标进入导航后附近的横线才会放大，悬停可预览那次提问和回答的开头，点击跳到那次提问并短暂高亮。按 Option+↑ / Option+↓（Windows 和 Linux 为 Alt+↑ / Alt+↓）跳到上一个或下一个提问；窗口较窄或打开工作台使左侧没有空间时，横线隐藏，快捷键仍可用。预览卡右上角可以给这次提问加书签，书签跟着会话保存，对应横线前会显示一个小圆点。

新会话准备就绪后即可发送首条消息，侧栏刷新不会阻塞发送。侧栏刷新失败会单独提示，不会把已经提交的消息恢复成草稿。
启动期间发现的资源更新会在后端空闲时提前加载；运行中发现的更新仍在下一轮开始前加载。重复扫描 Skill 时，如果资源没有变化，就不会再次触发后端重载。

失败回合会显示本地化原因，以及可安全展示的 HTTP 状态／请求 ID。临时故障提供 **重试**；凭据被拒或缺少模型时提供账号／模型设置入口。重试通过正常发送路径重新提交该回合原始用户内容，保留当前草稿；离线、打开中、停止中或已有回合运行时不可用。上下文、工作区、预算及步数限制问题须按提示修正。展开 **技术详情**可复制已记录的错误码、原因、消息和回合／会话标识。

### 添加文件和图片

点击发送按钮旁的回形针，也可以粘贴或拖入文件。每条消息最多 50 个附件，包括空文件。文件和图片统一按 1 MiB 顺序分块上传原件，并显示进度、校验和取消操作。原件单文件及每条消息合计最多 100 MiB；PNG/JPEG 视觉原件另限 20 MiB 和 6400 万像素。断线后可在同一个存活 worker 内重试续传；worker 重启后需要新上传。上传在 30 分钟后过期，会话关闭时清理；刷新页面后需要重新选择源文件。普通文件保留声明的 MIME；视觉图片根据实际字节核验格式。

原件字节属于所选 artifacts provider。服务端核验完整 SHA-256 后返回绑定 scope 的待确认回执；prompt 接纳时消费回执并保存引用。独立的工作区上传 API 保留自身配置上限和 `agnes-upload://` 路径语义；输入框原件上传不需要工作区写权限。移除已完成的草稿卡片只删除草稿引用，待确认回执到期前继续保守保护原件。历史图片按可见性加载授权缩略图，支持放大原件和原件下载，缺失或已回收的数据显示不可用占位；内部 artifact URI 不直接用于网络读取。

文字模型可接收图片文件但不获得视觉输入。视觉模型使用 provider 按模型限制缓存的派生版本，长边不超过 1456 像素并遵守更低的模型限制。原件保留原字节，包括合法 JPEG 尾迹；ledger 和 prompt 传输保存引用，不携带原件 Base64。`read` 接受 `session-file://12/1`、`session-image://12/1`，用 `session-file://list` 列出文件引用。查找检查当前会话、lane 和继承的 fork 边界；文件名和读取内容作为不可信数据。把原件保存到工作区仍需正常工作区写权限。

默认启用的 `@agnes/document-reader` 插件提供 `document_read`，读取 PDF、DOC、DOCX 和 ZIP。PDF 按指定页读取，没有文字的页面使用内置的离线中英文 OCR；文字层不完整时，用 `ocr: "always"` 强制识别，混合 PDF 逐页处理。Word 提取正文、表格和注释等文字，不还原排版或内嵌图片。ZIP 先列出文件名，再读取选定的文本或支持的文档，不解压到磁盘。不额外限制 ZIP 条目数量和合计展开大小；大成员不会挡住其他文件。选中文件解析仍共用 100 MiB 输入预算，长文字分页返回；OCR 像素、任务时间和并发数也有边界。不执行宏、链接或文档里的指令。禁用插件后停止解析，已上传文件仍保留。OCR 可能识别错；加密、损坏或不支持的文档会明确报错。

PDF 里的照片、图表和排版可以用 `mode: "image"` 按页看图，不运行 OCR，同时保留已有文字层。默认 `mode: "auto"` 在文字提取和 OCR 均无结果时也返回该页图片；`mode: "text"` 只返回文字。OCR 没识别到文字不等于空白页。页面图片沿用现有授权通道，并遵守所选模型的图片限制，历史图片也计入；最长边不超过 1456 像素，每张不超过 4 MiB，每次只渲染选定的一页。文字模型仍能读取提取出的文字，但要理解页面图片，需要可用的视觉通道；不会自动启用新的视觉服务。

当前安装的 pi-ai 聊天接口只有文字和图片输入，不接收原生文件、音频、视频内容块。二进制 Excel、演示文稿、音频、视频等尚不支持的格式仍可上传保存，但上传成功不等于模型已经读过。agent 必须如实说明读取失败的原因。GIF 等其他图片格式保留原始文件，避免悄悄只留下第一帧。

模型的 `inputLimits` 直接来自 pi-ai 模型目录；手动模型也可以声明同名字段。数量按当前模型声明的限制执行，不统一限制为 4 张。支持图片的 Agnes 模型每次完整请求最多 4 张，历史消息和工具返回的图片也计入。模型的图片字节上限按 Base64 编码长度计算，与上述 100 MiB 原始图片字节上限分别校验。处理后仍超限会拒绝添加，并保留已选附件；发送前还会重新检查整批图片。待发送消息共用一条队列记录，受 144 MiB 传输帧上限约束，并给包装预留 4 KiB。已能确定队列超过帧预算时，会在解码新媒体前拒绝；可接受的输入仍需通过格式校验和精确 UTF-8 帧大小校验才能保存。队列合计超限时会在保存前拒绝新消息；请等前面的消息处理完，或移除一条后重试。

附件可以单独发送，也可以与文字组合发送。任务运行时，新消息会作为 follow-up 排队。在文字模型下添加的图片会作为文件保存，不会提供视觉输入。切换模型保留草稿；原先按图片模型处理的图片仍需兼容模型才能发送。发送失败后，文字和附件会恢复，方便重试；切换会话时会清除尚未发送的附件。

长会话保留原图。图片选择遵守模型数量、字节和像素限制，优先保留当前轮。旧图按稳定步长省略最旧前缀，并随请求保存水位；扩大模型额度或重启不会复活已省略的旧图。缺失旧原件降级为文字占位；当前轮缺失或任何原件损坏仍拒绝请求。模型可通过授权工具主动读取旧图。

比较早期图片时，可以直接要求模型重新查看那些原图。已有的 `read` 工具可用 `session-image://list` 分页列出图片，再读取 `session-image://12/1` 这样的引用；整批读取使用 `session-image://12/1,34/2`。压缩上下文不会删除原图。每批调取都要符合模型和运行环境的图片限制；几十张图片应分批比较，需要同时看更多图片时选择支持相应数量的模型。

实际调用前会按执行模型再次检查本次选中的历史图片、当前图片及工具返回图片的数量与尺寸。切换模型不会自动删除草稿图片；不兼容时需换回支持的模型或移除图片。请求大小在 pi-ai 的供应商载荷回调中检查，支持 fetch 的通道还检查最终 HTTP 请求体；SDK 后续包装仍可能触发供应商限制。

本地 artifacts provider 在接纳前把内联图片、文件输入保存为持久引用。ACP 使用标准资源链接和有界附件元数据回放每个存储的图片、文件引用；兼容内联模式使用标准内嵌资源，URI 仅作名称。Web 分块上传原件也使用 artifact 引用；独立工作区上传 API 保留 `agnes-upload://` 身份。重新打开会话时，通过授权读取重建图片预览和文件卡片。保留内联内容的可选 provider 仍受传输帧和投影预算限制。`artifact.read` 只负责读取。诊断和脱敏导出隐藏原件字节；原生 raw 导出在配套 artifact 目录中保留经过核验的原件。

打开输入框旁的模型选择器。模型按账户分组，右侧显示各模型容量。「本会话」三行显示当前的思考强度、上下文窗口和辅助模型。点击一行，在同一弹层内进入子面板；Enter 或右方向键进入，Esc 或左方向键返回，主面板再按 Esc 关闭。思考档位来自当前模型。上下文可选自动、容量范围内的预设或自定义；自定义输入框单位固定为 K，输入 `100` 表示 100,000 Token，留空恢复自动。选值立即生效并收起菜单，手填预算在按回车或离开输入框时提交；容量上下界校验保持生效。设置影响后续请求，重新打开会话也会保留。

辅助模型选择后立即用于当前会话，并弹出确认提示。「跟随默认」显示具体默认模型；设置链接打开「模型与账户 → 辅助模型」。默认值用于新会话，已有会话保留自己的选择。

未保存语言选择时，界面跟随浏览器首选语言（支持英文与简体中文），其他语言回落英文；在“设置 → 通用 → 语言”保存的选择优先。切换语言会重新翻译已有的平台错误和恢复提示，已记录的工具输出保留原文。自动标题优先使用模型从首条消息中判断出的语言，例如在中文界面发送“Hi”，仍生成英文标题。无法判断时，包括混合语言没有明显主语言，或只有代码、标识符、数字、表情等内容时，模型使用提交该消息时传入的界面语言。这些语言规则通过提示词约束；输出只校验格式，不替换语言，也不额外调用模型。切换界面语言不会翻译已有标题，也不会覆盖手动命名。

失败回合会在状态下直接显示后台记录的错误码和原因，折叠过程也不会隐藏错误；重开会话后仍可查看。旧记录没有具体错误详情时会明确说明。

### 查看轨迹

从“对话”切换到“轨迹”，可按轮次和步骤查看会话。选择记录可查看状态、耗时、错误和可用的 token 用量。时间图提供四种顺序与耗时模式：拖选可筛选，滚轮可缩放，右键拖动可平移，按 Esc 可清除范围。

可折叠轮次和工具调用、搜索记录或加载更早历史。“投影内容”中的工具参数和结果是预览；选择“完整输入”或“完整输出”可按需读取已记录的详情。“时间”页显示已记录的时间字段。缺少的时间、用量或历史会明确标注，不作估算。

窄屏下从记录列表选择时间图中的事件，图表保留总览。选中详情会使用完整内容区；点击关闭详情或按 Escape 回到原记录。切回“对话”即可使用输入框。设置分类可横向滚动，输入框的选项芯片会换行，保持操作区域可用。

## 日常管理

侧栏的「视图选项」菜单可以把会话按工作区分组或排成单列表，并按「隐藏已归档 / 全部对话 / 仅显示已归档」筛选。在「筛选会话」里选「仅显示已归档」可以只看归档。这些筛选都包含空闲和已完成的会话，不表示任务正在执行。

设置中管理模型账号、插件、Skills/MCP、外观及 Computer Use；可用项受后台能力和权限约束。插件安装后还要信任与启用，见[插件管理](packages.zh-CN.md)。侧栏可以重新选择历史会话；归档的任务在「视图选项」的「仅显示已归档」里查找，归档并不等于删除历史。

Computer Use 显示驱动状态、系统权限、诊断与维护进度。切换设置页时继续监控进度；面板替换或重新加载后读取最新操作，不重新提交。移除面板只停止本地监控；需要取消后台操作时，显式点击“取消操作”并等待确认。连接失败或等待时间较长不能证明操作已经完成或取消。

接入 MCP 时，可以在聊天中说明“帮我接入这个 MCP”并提供服务地址或连接信息，再到设置中查看详情；新建的服务需要依次信任和启用，详见[MCP 接入](mcp.zh-CN.md)。涉及凭据时使用 SecretRef 配置流程。

页面通过 URL 的 `session` 参数选择会话。会话打开后会清理一次性的示例启动参数，刷新恢复当前对话。刷新和短暂断线后，SDK 从后台重新读取投影，不自行重发业务请求。重新连接失败时先查看 `daemon status`；后台重启后用当前 `serve` 输出的普通地址打开。运行中的 `serve` 会自行重新连接到同一 home、profile 和 Web 来源的已重启后台：等待期间管理请求返回“后台不可用”（HTTP 503）而不是内部错误，后台恢复后页面自动重新载入。它不会自行启动后台，并拒绝身份或 Web 来源不同的后台；遇到这种情况请重新运行 `serve`。当前本地模式无需从 sessionStorage 恢复启动 token。

关闭浏览器、主动断开页面或结束 `serve` 只影响客户端/Web 服务。后台任务是否结束以会话事实为准。完全结束实验实例需要另行 `daemon stop`。

### 定时任务

「自动化」页列出定时任务。每个任务都要选在哪里运行：

- **新会话**（默认）：每次运行都在所选工作区开一个新会话，以任务名和开始时间命名，再在里面运行。还可以选执行方式或业务 Agent、预设和模型；不选的项与新会话的默认值相同。业务 Agent 的权限预设和模型由它自身固定，表单会显示实际值并锁定这两项。
- **现有会话**：到点把任务发到一个会话。会话空闲时开始一轮，正在运行时并入当前一轮。

一次性任务即使已没有下一次调度，只要本次仍在运行或等待人工处理，就会保留在默认列表中。本次完成或失败后，可以打开「包含已归档」查看记录。

频率可选一次、每隔若干分钟或小时、每天、每周或 Cron 表达式，默认用这台电脑的时区。保存前表单会显示下次运行时间。每一行显示运行位置、规则、下次运行、启用开关和上次结果；菜单里有立即运行、编辑和归档。运行记录逐条显示运行中、等待审批、已运行、已送达或失败，附耗时、失败原因和会话链接。运行遵守正常的审批策略：需要审批时和其他会话一样等待，运行记录会链接到它。电脑没开时错过的重复任务，只补最近一次。新会话任务运行到一半时 AGH 停止或崩溃，重启后这次运行不会再跑一遍，因为它可能已经开了会话、发出了提示：它记为失败，原因是运行期间 AGH 停止了；重复任务继续等下一次运行。还没开会话的运行，以及发到现有会话的任务，仍和以前一样重新运行。会话的运行信息里也会列出这个会话接收或创建的定时任务。

在对话里说「每天早上帮我整理……」这类重复的工作，会在当前工作区建一个新会话任务；「30 分钟后提醒我」「明早继续这个任务」这类一次性提醒发到当前会话。回复会说明任务在哪里运行。工具说明见[默认工具](../reference/default-tools.zh-CN.md)。

### 结果收取、搜索和运行历史

定时任务页可切换「任务」和「结果收取」。「结果收取」集中展示已结束运行的简短结果、未读状态及完整会话和附件入口，可标为已处理或重新标为未读。这只改变结果的阅读状态，不会回答或解除审批。提示仅送入忙碌会话的记录仍标为「已送达」，不当作任务已完成；没有保存摘要时会明确提示。摘要只提取运行期间最终答复的正文，最多 4,000 字符，不保存思考内容；完整结果仍在会话中。拒绝答复、达到输出上限时已有的正文也会保留摘要；失败运行仍显示失败状态和原因。

任务可按名称或指令搜索，按工作区、启用、暂停、结束、归档、失败或待处理状态筛选。失败筛选以最近一次运行判断，待处理筛选保留仍等待人工处理的运行。状态筛选可以查看已结束或归档任务；「包含已归档」控制默认列表。分类、搜索、状态和工作区筛选均在返回条数限制前完成；搜索字段与前端使用相同的 Unicode 小写规则，带重音字符的名称也可按此规则匹配。筛选后列表为空时，也会在任务到期或完成后更新。

每个任务的「查看运行历史」按保存顺序从新到旧分页读取，每页 20 条，可加载更早记录。历史全量保留在本机，不按天数或条数自动清理，归档任务也不删除历史。记录保存当次任务指令、时间规则和已选择的运行设置快照；未指定的设置仍遵循该次会话的默认值。缺少快照或摘要时会标明，不能用当前配置替代。查询使用任务与顺序索引，全局未读和指定任务未读分别使用对应索引，不用偏移量从头翻页。本次使用数据目录格式 2：空库直接创建最终结构，旧格式会被拒绝打开，不改写、不迁移数据；切换版本前请阅读[数据格式与升级](install.zh-CN.md#数据格式与升级)。历史全量保留指正常使用期间不自动清理，重置数据目录仍会丢失历史。读取失败保留已加载记录，刷新可重试；切换任务后迟到的响应不会覆盖当前历史。展开的历史处于最新一页时，会跟随任务列表更新；加载更早记录后，后台更新不会替换当前页；点击「刷新记录」回到最新一页。标记已处理会保留已加载的页面，后面还有未读记录时仍可继续加载。在最新一页标记时，若恰好有新的运行结束，收到标记结果后会补读并显示新结果。

## 当前交互边界

内置右栏文档预览支持文本、代码、Markdown、经过过滤的 HTML，以及由会话资源服务提供的图片或 PDF。资源读取失败时显示通用的不可用提示；截图已被回收时显示保留策略清理提示。替换或关闭预览会释放其取得的资源 URL，并忽略迟到回复。关闭预览不会取消后台工作。工作台 CSP 允许图片和框架加载本地 Blob URL，仍拒绝远程来源，PDF 框架保留 sandbox。其他页面维持原有 CSP。部分浏览器不允许在 sandbox 框架中运行原生 PDF 查看器，这些浏览器无法显示内嵌 PDF 预览。

工具结果以受约束预览/详情呈现，不是任意 HTML。不要推定每种产物都支持上传、下载、重命名，或每条消息都有编辑/重新生成；界面只暴露当前后端支持的动作。真实浏览器全链路的验证范围见[验证记录](../maintainers/verification.zh-CN.md)。

实现依据：[Web 入口](../../packages/web/src/serve-entry.ts)、[应用](../../packages/web/src/app.ts)、[服务与来源校验](../../packages/web-server/src/server.ts)、[会话操作](../../packages/web/src/session-actions.tsx)。

## 终端与后台任务

打开会话，在工作台选择**终端**。引导卡使用上次选择的 Shell 新建终端（macOS 默认 zsh，Windows 默认 pwsh，其他平台默认 bash），旁边的箭头可选择其他 Shell。有页签时，点击 **+** 使用记住的 Shell；右键、长按或聚焦 **+** 后按 Shift+F10，可选择 Shell 或连接 Agent 的任务。

xterm.js 画面跟随应用主题，保留 ANSI/OSC 颜色，并随面板大小调整 PTY。聚焦画面后可以输入、粘贴（每次最多 64 KiB UTF-8）、使用方向键或 Ctrl+C。刷新会重新连接同一 PTY。双击用户终端的页签名称，或在菜单中选择**重命名**，可就地改名；Enter 或失焦保存，Escape 取消。名称按会话保存在当前浏览器。

右键页签或按 Shift+F10，可中断、查看会话／任务 ID／工作目录或终止用户终端。用户终端的 **×** 会结束运行中的进程并关闭页签；Agent 页签的 **×** 只取消跟随。关闭工作台只断开界面，进程仍运行。打开工作台不会自动启动终端，需要时再新建。用户终端连续 2 小时无人输入、查看、也没有输出时会被关闭；Agent 的持久 shell 在没有命令运行的情况下闲置 30 分钟后关闭；后台命令不会因此被关闭。Agent 执行的命令从 `/dev/null` 读取输入，需要交互输入的命令会直接失败，而不是一直等待。Agent 的任务只读。退出码显示在画面末尾，页签以灰点表示零、红点表示非零。输出截断和输入已满提示位于顶部，可关闭。输出采用有上限的快照：两次轮询间丢失的文本或保留尾部之前的内容无法恢复。

旧链接 `/?settings=terminal` 会打开可用会话工作台中的终端。如果没有打开会话，则关闭设置并提示先打开会话再使用终端。

设置中的后台任务页按会话标题、工作区名和相对时间选择会话，自动读取当前会话并持续更新。它显示 shell 命令、持久解释器、PTY 和子代理的状态与输出。人类拥有的运行中任务可通过行菜单终止，并须再次确认；Agent 所属任务只能查看，请在会话中要求 Agent 停止。所有操作遵守所属会话的沙箱预设。

共享终端与后台任务界面通过会话锁定的服务绑定调用 `jobs.read` 和 `jobs.control`。在会话组合中禁用官方提供方后，替代插件可以实现同一合同，或提供自己的客户端界面。同一合同存在多个提供方时会拒绝调用。进程策略、会话归属、服务授权和持久控制回执仍由平台执行。后台任务管理也可从**设置 → 高级 → 作业**进入。

`agnes/jobs-web` 扩展需要 capability ceiling 的 `services`。新模板已包含；旧配置可显式添加。未添加时 shell/作业工具继续可用，Web 控制不可用。任务可跨页面刷新和轮次保留，Host 重启后不会恢复。本地 PTY 支持 macOS/Linux；缺少 shell 或不支持交互执行的提供方会明确报错。

已保存的网页搜索服务可以处于就绪状态而尚未设为默认。搜索设置在就绪服务旁显示「用作默认服务」，并说明选定默认服务后才能测试。配置抽屉同时提供启用和默认控件；保存失败时保留原有搜索状态。

## 回复建议

内置「回复建议」插件默认启用，可在 **插件 → 内置** 中按常规插件方式开关。实时回复成功完成后，它使用已配置的**辅助模型（fast）**生成一个简短的后续问题，以灰字显示在空输入框内。按 **Tab** 填入后可编辑再发送；输入文字会隐藏建议，**Escape** 会关闭本回合建议，空输入框按 **Enter** 不会发送建议。开始新回合、切换会话或刷新页面后建议失效。建议不会写入对话记录或模型上下文。未配置辅助模型、生成失败或超过五秒时静默略过；辅助调用按正常方式记录用量。全新会话仍使用原有的目录任务提示。

## 旁路提醒

**旁路提醒**默认关闭，是按会话设置的：打开会话菜单，选择**运行时**，再开启**旁路提醒**。开启后，在有副作用的工具结果（执行命令、写文件、编辑、删除）之后和每轮结束时，旁路模型会审查智能体的工作，并在它下一次模型请求时递上一条简短的参考性提醒。每次审查会把到目前为止的对话（与 `/btw` 发送的视图相同）、最近一条用户请求和本轮工具调用的截断摘要（工具名、参数的前 200 个字符、成功或失败）发给**验证模型**，没有验证模型时发给**快速模型**；两者都没配置时不发送任何内容。每次审查按 `side-call` 费用行计费。提醒最多 300 个字符，已去除控制字符，只送达智能体一次，并标明仅供参考、不是用户指令；回合结束后它还会以**旁路提醒**横幅显示在输入框上方，可以关闭。同一时间最多运行一个审查，回合中的审查至少间隔 20 秒，已给过的提醒不会重复，每个会话每小时最多产生 6 条。它不会拦截工具、不会改变权限，也不会替用户审批。关闭后立即停止审查，并丢弃尚未送出的提醒。该开关属于正在运行的会话，会话重新打开后恢复为关闭。终端界面用 `/heads-up on|off` 控制同一个开关。

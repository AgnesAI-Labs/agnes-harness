# Web 工作台：集中管理任务与扩展

[English](web.md) | 简体中文

[文档导航](../README.zh-CN.md) · [首次配置](quickstart.zh-CN.md)

Web 工作台把任务、历史和管理操作放在一个本地界面中。首次使用按[快速开始](quickstart.zh-CN.md)配置模型；本页带你理解一次任务的状态、日常管理和连接方式。

## 启动与连接

```sh
node packages/cli/dist/local/agnes.mjs serve
```

Web 监听本机回环地址。当前页面不接收或保存本地连接 token；服务按启动时固定的 Origin 与 Host 校验连接。`localhost` 与 `127.0.0.1` 不能随意互换。改端口时设置一致的来源：

```sh
export AGNES_WEB_ORIGIN=http://127.0.0.1:4180
node packages/cli/dist/local/agnes.mjs serve --port 4180
```

若旧后台使用不同 Origin，新启动会拒绝复用；先确认任务状态并显式停止该实例，再启动。它不是远程公开站点部署入口，也没有本文承诺的反向代理登录方案。

页面的会话与审批通信通过浏览器 SDK 的 WebSocket 直连 daemon；资源/插件管理和插件后端服务使用同源 HTTP BFF。两者都是本地工作台的一部分，详见[通信架构](../develop/architecture.zh-CN.md#web-的两条通信路径)。

## 完成一轮任务

1. 从侧栏新建任务，在创建面板确认工作目录；取消面板不会创建会话。
2. 从模型选择器选当前会话使用的 route/model。Provider 默认配置和当前会话选择是不同操作。
3. 输入消息，点击发送或 Cmd/Ctrl+Enter；运行中继续发送会排队为 follow-up，当前轮正常完成后按顺序自动执行。停止、执行失败或等待审批时暂停自动继续，未执行的输入保留在队列中。停止或失败后发送新消息，会先按顺序执行保留的输入，再执行新消息。
4. 待执行消息显示在输入框上方，包含数量和顺序；重新打开或重连后也能恢复。点击某条消息的“立即发送”，会先停止当前轮，再优先执行选中的消息；其他消息保持原有顺序，在它正常完成后继续执行。点击“删除”只移除该条待执行消息，不会停止当前轮或启动排队任务，其他消息顺序保持不变。这是从执行队列中移除，原始事件仍保留在会话历史中。已开始执行的消息不能删除，也不会重复发送。操作失败时，错误显示在队列旁，并刷新列表。

5. 按工具记录阅读参数、结果及错误详情。思考文本、工具状态和用量来自后台投影；没有返回的内容不会凭空补全。
6. 需要审批时检查实时选项和授权范围。提交后等待后台确认，不用页面按钮是否消失判断工具已执行。
7. 点击“停止”后等待实际终止状态。“正在请求停止”只表示已发起取消。

新会话准备就绪后即可发送首条消息，侧栏刷新不会阻塞发送。侧栏刷新失败会单独提示，不会把已经提交的消息恢复成草稿。
启动期间发现的资源更新会在后端空闲时提前加载；运行中发现的更新仍在下一轮开始前加载。重复扫描 Skill 时，如果资源没有变化，就不会再次触发后端重载。

### 添加文件和图片

点击发送按钮旁的回形针，也可以粘贴或拖入文件。入口允许各类文件，包括空文件；每条消息最多 50 个附件，合计不超过 100 MiB。文字模型也能添加附件。当前模型支持图片时，PNG、JPEG 走图片输入，并额外遵守合计 800 万像素的限制。图片会先按 1456 像素长边和模型声明的更低尺寸限制缩小，所以字节上限看的是处理后的数据。浏览器能解码但严格校验不接受的 JPEG（例如带尾部附加数据的文件）会先重新编码；普通小图保留原样。服务端校验附件名称、MIME 类型、规范 Base64 和合计大小；原生图片还需通过结构和尺寸校验。附件编码后放入 JSON 消息，因此也受 144 MiB WebSocket 帧上限约束。

文件原始字节保存在会话记录里，每次请求只把引用和必要信息交给模型，不反复发送整个 Base64。已有的 `read` 工具可以用 `session-file://12/1` 分页读取 UTF-8 和带 BOM 的 UTF-16 文本，用 `session-file://list` 查找旧附件。CSV、TSV 按实际文本内容读取，即使文件类型被标为 Excel。文件名和读取内容都作为不可信数据处理。附件只能在所属会话和分支里读取，文件名不会用于拼接磁盘路径。

默认启用的 `@agnes/document-reader` 插件提供 `document_read`，读取 PDF、DOC、DOCX 和 ZIP。PDF 按指定页读取，没有文字的页面使用内置的离线中英文 OCR；文字层不完整时，用 `ocr: "always"` 强制识别，混合 PDF 逐页处理。Word 提取正文、表格和注释等文字，不还原排版或内嵌图片。ZIP 先列出文件名，再读取选定的文本或支持的文档，不解压到磁盘。不额外限制 ZIP 条目数量和合计展开大小；大成员不会挡住其他文件。选中文件解析仍共用 100 MiB 输入预算，长文字分页返回；OCR 像素、任务时间和并发数也有边界。不执行宏、链接或文档里的指令。禁用插件后停止解析，已上传文件仍保留。OCR 可能识别错；加密、损坏或不支持的文档会明确报错。

PDF 里的照片、图表和排版可以用 `mode: "image"` 按页看图，不运行 OCR，同时保留已有文字层。默认 `mode: "auto"` 在文字提取和 OCR 均无结果时也返回该页图片；`mode: "text"` 只返回文字。OCR 没识别到文字不等于空白页。页面图片沿用现有授权通道，并遵守所选模型的图片限制，历史图片也计入；最长边不超过 1456 像素，每张不超过 4 MiB，每次只渲染选定的一页。文字模型仍能读取提取出的文字，但要理解页面图片，需要可用的视觉通道；不会自动启用新的视觉服务。

当前安装的 pi-ai 聊天接口只有文字和图片输入，不接收原生文件、音频、视频内容块。二进制 Excel、演示文稿、音频、视频等尚不支持的格式仍可上传保存，但上传成功不等于模型已经读过。agent 必须如实说明读取失败的原因。GIF 等其他图片格式保留原始文件，避免悄悄只留下第一帧。

模型的 `inputLimits` 直接来自 pi-ai 模型目录；手动模型也可以声明同名字段。数量按当前模型声明的限制执行，不统一限制为 4 张。支持图片的 Agnes 模型每次完整请求最多 4 张，历史消息和工具返回的图片也计入。模型的图片字节上限按 Base64 编码长度计算，与上述 100 MiB 原始图片字节上限分别校验。处理后仍超限会拒绝添加，并保留已选附件；发送前还会重新检查整批图片。待发送消息共用一条队列记录，受 144 MiB 传输帧上限约束，并给包装预留 4 KiB。队列合计超限时会在保存前拒绝新消息；请等前面的消息处理完，或移除一条后重试。

附件可以单独发送，也可以与文字组合发送。任务运行时，新消息会作为 follow-up 排队。在文字模型下添加的图片会作为文件保存，不会提供视觉输入。切换模型保留草稿；原先按图片模型处理的图片仍需兼容模型才能发送。发送失败后，文字和附件会恢复，方便重试；切换会话时会清除尚未发送的附件。

长会话会保留记录里的原图。平常只在模型额度内发送最近三条带图用户消息中的图片；这是历史窗口，不是每次只能上传三张。新附件会整批发送，无法容纳时明确报错。模型主动调取旧图时，最近一次调取的整批图片优先于其他旧图和截图。没送入本次请求的图片会保留引用、已有文字说明，并提示不能猜测未看到的细节。压缩上下文时也使用这套限制，不额外调用模型生成图片摘要。

比较早期图片时，可以直接要求模型重新查看那些原图。已有的 `read` 工具可用 `session-image://list` 分页列出图片，再读取 `session-image://12/1` 这样的引用；整批读取使用 `session-image://12/1,34/2`。压缩上下文不会删除原图。每批调取都要符合模型和运行环境的图片限制；几十张图片应分批比较，需要同时看更多图片时选择支持相应数量的模型。

实际调用前会按执行模型再次检查本次选中的历史图片、当前图片及工具返回图片的数量与尺寸。切换模型不会自动删除草稿图片；不兼容时需换回支持的模型或移除图片。请求大小在 pi-ai 的供应商载荷回调中检查，支持 fetch 的通道还检查最终 HTTP 请求体；SDK 后续包装仍可能触发供应商限制。

图片和文件以内联内容保存在用户消息和会话事件记录中，并随会话历史保留。文件新增为 `file` 内容块，不改变原有文字、图片格式；ACP 发送和回放复用标准内嵌资源，并声明支持 `embeddedContext`。内嵌文字和二进制资源都保存为附件，URI 仅作名称，不会据此下载或读取磁盘文件。使用文件附件需更新配套客户端和后端。Web 请求的历史投影读取预算为 144 MiB 减去给传输包装预留的 4 KiB，协议默认读取预算仍为 256 KiB。工作进程的历史读取结果超过单帧上限时，会拆成更小的消息序号范围读取，保留原有顺序和完整结果。重新打开会话时，界面会重建图片缩略图和文件卡片。读取预算较小的旧客户端可能无法恢复大附件消息。这不是产物上传流程，`artifact.read` 也不接收浏览器上传的文件。诊断和默认导出会隐藏附件的编码内容，延续图片、音频已有的处理规则。

打开输入框旁的模型选择器。把鼠标移到某个模型上，列表旁边就显示该模型的会话设置：模型容量、思考强度、上下文窗口。档位按该模型支持的能力显示。打开上下文窗口可以选预设，也可以填完整 Token 数量或带 `K`/`M` 单位：`100K` 表示 100,000 Token，`100` 只表示 100 Token，对普通模型过小，无法保存；留空可恢复自动。改完立即生效并收起菜单，手填的预算在按回车或离开输入框时提交。给非当前模型选值时，会先切换到那个模型。设置影响后续请求，重新打开会话也会保留。账户设置里的配置作为新会话默认值；默认值变化不会覆盖已有会话。

在“设置 → 外观”选择英文或简体中文。自动标题优先使用模型从首条消息中判断出的语言，例如在中文界面发送“Hi”，仍生成英文标题。无法判断时，包括混合语言没有明显主语言，或只有代码、标识符、数字、表情等内容时，模型使用提交该消息时传入的界面语言。这些语言规则通过提示词约束；输出只校验格式，不替换语言，也不额外调用模型。切换界面语言不会翻译已有标题，也不会覆盖手动命名。

失败回合会在状态下直接显示后台记录的错误码和原因，折叠过程也不会隐藏错误；重开会话后仍可查看。旧记录没有具体错误详情时会明确说明。

### 查看轨迹

从“对话”切换到“轨迹”，可按轮次和步骤查看会话。选择记录可查看状态、耗时、错误和可用的 token 用量。时间图提供四种顺序与耗时模式：拖选可筛选，滚轮可缩放，右键拖动可平移，按 Esc 可清除范围。

可折叠轮次和工具调用、搜索记录或加载更早历史。“投影内容”中的工具参数和结果是预览；选择“完整输入”或“完整输出”可按需读取已记录的详情。“时间”页显示已记录的时间字段。缺少的时间、用量或历史会明确标注，不作估算。

## 日常管理

设置中管理模型账号、插件、Skills/MCP、外观及 Computer Use；可用项受后台能力和权限约束。插件安装后还要信任与启用，见[插件管理](packages.zh-CN.md)。侧栏可以重新选择历史会话；归档的任务从对应归档入口查找，归档并不等于删除历史。

Computer Use 显示驱动状态、系统权限、诊断与维护进度。切换设置页时继续监控进度；面板替换或重新加载后读取最新操作，不重新提交。移除面板只停止本地监控；需要取消后台操作时，显式点击“取消操作”并等待确认。连接失败或等待时间较长不能证明操作已经完成或取消。

接入 MCP 时，可以在聊天中说明“帮我接入这个 MCP”并提供服务地址或连接信息，再到设置中查看详情；新建的服务需要依次信任和启用，详见[MCP 接入](mcp.zh-CN.md)。涉及凭据时使用 SecretRef 配置流程。

页面通过 URL 的 `session` 参数选择会话。刷新和短暂断线后，SDK 从后台重新读取投影，不自行重发业务请求。重新连接失败时先查看 `daemon status`；后台重启后用当前 `serve` 输出的普通地址打开。当前本地模式无需从 sessionStorage 恢复启动 token。

关闭浏览器、主动断开页面或结束 `serve` 只影响客户端/Web 服务。后台任务是否结束以会话事实为准。完全结束实验实例需要另行 `daemon stop`。

## 当前交互边界

内置右栏文档预览支持文本、代码、Markdown、经过过滤的 HTML，以及由会话资源服务提供的图片或 PDF。资源读取失败时显示通用的不可用提示；截图已被回收时显示保留策略清理提示。替换或关闭预览会释放其取得的资源 URL，并忽略迟到回复。关闭预览不会取消后台工作。工作台 CSP 允许图片和框架加载本地 Blob URL，仍拒绝远程来源，PDF 框架保留 sandbox。其他页面维持原有 CSP。部分浏览器不允许在 sandbox 框架中运行原生 PDF 查看器，这些浏览器无法显示内嵌 PDF 预览。

工具结果以受约束预览/详情呈现，不是任意 HTML。不要推定每种产物都支持上传、下载、重命名，或每条消息都有编辑/重新生成；界面只暴露当前后端支持的动作。真实浏览器全链路的验证范围见[验证记录](../maintainers/verification.zh-CN.md)。

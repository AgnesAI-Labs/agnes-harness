# 和智能体说话：听写、语音对话与朗读

[English](voice.md) | 简体中文

[文档](../README.zh-CN.md) · [通用凭据](credentials.zh-CN.md) · [使用 TypeSafe Jev 做旁路模型调用](typesafe-jev.zh-CN.md) · [网络部署](deployment.zh-CN.md) · [API 与 Schema](../reference/api.zh-CN.md)

Web 对话框可以听你说话，也可以把智能体的回答读出来。三项功能都是内置的，通过同一个**语音账户**使用：

- **听写**：话筒按钮把一段口述变成输入框里的文字。
- **语音对话**：声波按钮进入免动手的循环：你说话，消息发出，回复读给你听，然后继续听。
- **朗读**：每轮最终回复下面有一个按钮，点一下就读；也可以设成每条回复都自动朗读。

语音账户是“旁路模型”里使用**语音**适配器的一个条目。它把录音发给你选的服务商的语音识别模型，把回复文字发给它的语音合成模型。不需要安装任何东西，也不会动用对话模型。

## 添加语音账户

在 设置 → 模型与账户 页面，展开「高级：旁路模型与任务模型」，点「添加旁路模型」，把适配器选成**语音**。再选一个服务商，它会填好端点和两个模型，表单只需要你选凭据：

| 服务商 | 端点 | 识别模型 | 朗读模型 | 默认音色 |
| --- | --- | --- | --- | --- |
| 硅基流动（默认） | `https://api.siliconflow.cn/v1` | `FunAudioLLM/SenseVoiceSmall` | `FunAudioLLM/CosyVoice2-0.5B` | `anna` |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini-transcribe` | `gpt-4o-mini-tts` | `alloy` |
| 阶跃星辰 | `https://api.stepfun.com/v1` | `stepaudio-3-asr-max` | `stepaudio-3-tts` | `cixingnansheng`（磁性男声） |

- 端点和两个模型 ID 都可以改。任何兼容 OpenAI 语音接口的端点都能用。端点规则和其他旁路模型一样：绝对的 HTTPS 地址，纯 `http` 只允许回环地址，不能带凭据、模板、查询串或片段。
- 使用阶跃国际站时，把端点改成 `https://api.stepfun.ai/v1`。阶跃的识别接口是它自己的请求格式，不是 OpenAI 的；适配器按模型名自动切换，不需要配置。
- 某个模型栏留空，对应的功能就不可用。至少要填一个，两个不能相同。
- 选一个[通用凭据](credentials.zh-CN.md)，或当场新建一个。条目保存的是它的引用。密钥留在凭据库里，只由本机后端使用，不会发到浏览器。
- **测试连接**请求一次 `GET <端点>/models`，确认端点有响应、密钥被接受，不会调用模型，也不产生费用。成功或被限流都算可达，密钥被拒绝会单独指出。测试是可选的。
- 可选的输入价格单位是每百万单位的美元数，单位对朗读是文字字节，对识别是音频秒数。见[费用与限制](#费用与限制)。

对话已经打开时新增的语音账户会被该对话直接用上，不需要刷新页面。

### 多个语音账户

只有一个已启用的语音账户时自动使用它。有多个时，打开 设置 → 语音，在**语音账户**下拉框里选一个。下拉框列出旁路模型页里语音账户的名称。选定之前，按钮保持置灰，原因是“有多个语音账户，请在设置里选一个”。已禁用的账户不计入。

## 设置

设置 → 语音（在“通用”分组）里有下面这些设置。改动自动保存，立即生效，已经打开的对话也一样。

| 分组 | 设置项 | 默认 | 说明 |
| --- | --- | --- | --- |
| 通用 | 语音账户 | 自动（唯一的语音账户） | 语音账户的下拉框 |
| 语音输入 | 开启语音输入 | 开 | 关闭后话筒和声波按钮都不显示 |
| | 识别语言 | 空 | 留空由服务商自动判断；填 `zh`、`en`、`zh-CN` 这样的代码 |
| | 说完自动发送 | 关 | 关闭时识别出的文字先放进输入框，让你看一眼再发给智能体 |
| | 单次最长录音（秒） | 120 | 5 到 120 的整数 |
| 朗读 | 开启朗读 | 开 | 关闭后朗读按钮和声波按钮都不显示 |
| | 音色 | 空 | 留空时按朗读模型 ID 取默认音色：含 `/` 的 ID 用 `<模型>:anna`，阶跃模型用 `cixingnansheng`，其他用 `alloy` |
| | 语速 | 1 | 0.25 到 4；1 为正常语速 |
| | 自动朗读回复 | 关 | 回复常常很长，每轮都读既吵又花钱 |
| 语音对话 | 停顿多久算说完（秒） | 1.2 | 0.5 到 5 |

分组里还写着隐私提示，并有一个**去配置**按钮，打开旁路模型页。语音输入和朗读都关闭时，对话框里没有任何语音按钮。

在硅基流动上，音色的完整写法是 `<朗读模型>:<名字>`，只填名字（如 `anna`）就够了。阶跃只支持 0.5 到 2 的语速，超出范围时按最近的边界值发送。语速正好是 1 时不会发送这个参数，这样普通请求在所有服务商上都能用。

## 听写

发送按钮旁边有两个按钮。新会话的空白页上也有：第一次录音会先替你建立会话，和上传附件的做法一样。

1. 点话筒。按钮显示已录秒数和音量。第一次使用时浏览器会请求话筒权限。
2. 再点一下结束，录满最长时长也会自动结束。按 Esc 取消，这时 Esc 不会顺带关掉侧边栏。
3. 识别期间按钮转圈。识别出的文字插到输入框的光标处；开了**说完自动发送**就直接发送。

没识别出内容时，提示“没听清，请再说一次”。开始录音会停止正在进行的朗读。

## 语音对话

点声波按钮。按钮变成“进行中”的样子，旁边的状态词随循环变化：

1. **在听**：自动开始录音，声波随音量跳动。你开口之后停顿超过设定的时间（默认 1.2 秒），这句话就算说完。
2. **识别中**：识别出的文字立即发送，不管**说完自动发送**怎么设。没识别出内容就回到“在听”。
3. **在想**：等这一轮结束。智能体要审批或向你提问时，照常在界面上处理，处理完继续等。
4. **在读**：朗读这一轮的最终回复，不管**自动朗读回复**怎么设。朗读时不录音，免得录进自己的声音。
5. 回到**在听**，接着听下一句。

这是半双工：要么听，要么说，不会同时。

- **打断**：朗读时点话筒，朗读停止，马上开始听。
- **退出**：再点一下声波按钮、按 Esc、切换到别的会话，或在“在听”状态 30 秒没人说话。
- 这一轮失败、被取消或没有最终回复时，会提示一句，然后回到“在听”。
- 同一时间只有一个浏览器标签页能进入语音对话，其他标签页的声波按钮置灰。

## 听回复

账户配了朗读模型后，每轮的**最终回复**下面有**朗读**按钮，播放时变成**停止**。中间的过程消息和还在生成的回复上没有这个按钮。没有朗读模型时这个按钮根本不显示。

开了**自动朗读回复**，你正在看的会话每轮结束时会自动朗读最终回复。打开历史会话、重新连接、切换会话都不会触发。同时开着多个标签页时只有一个会读。浏览器拦截自动播放时，按钮上写着“点击播放”，点一下就开始。

代码块、表格、分隔线、链接地址和 Markdown 标记不会被读。文字在句末切成片段（长句在逗号处再切），每个片段在需要时才合成。

## 隐私

录音和回复文字会通过你本机的后端发给所选账户的服务商：浏览器从不直接联系服务商，也拿不到密钥。回复按片段发送，录音按最长 20 秒一段发送。录音不会保存在本地请求追踪里，追踪会把一次调用里的音频换成占位符。服务商那边如何保留数据，取决于你和它的协议，所以你说的话和被朗读的回复里的个人信息和机密仍要照常小心。

## 费用与限制

- **话筒**：浏览器只在 `localhost` 或 https 页面上开放话筒。Web 服务只监听本机，所以本机打开或通过 SSH 端口转发打开都没问题。如果自己用纯 `http` 的反向代理把它放到别的地址，话筒会被浏览器拦掉，朗读不受影响。
- **录音**：默认最长 120 秒（可在 5 到 120 之间调整）。网页按最长 20 秒一段发送（后端容许多出半秒），再把各段文字拼起来。
- **朗读片段**：每段最多 120 个字符，按 UTF-16 码元计数，所以一个表情符号算 2 个。
- **频率**：每个会话同时只能有一次识别和两次朗读在进行，每分钟最多受理 30 次调用。超出的调用被直接拒绝，不排队；调用刚结束还没释放时网页会短暂重试。
- **时限**：一次调用的期限是 30 秒。
- **费用**：每次到达服务商的调用都会在会话账本里写一条 `side-call` 费用行，标签是 `voice.transcribe` 或 `voice.speak`。识别按音频秒数（向上取整）计，朗读按文字的 UTF-8 字节数计。这也是可选输入价格所用的单位。单次请求预算照常生效。会话有树预算且已有回合时，调用会在该预算里预留；还没有回合的新会话里，调用不属于任何树预算。

## 排查

置灰的按钮会自己解释原因：悬停或点击就能看到。前四种原因的气泡里还有**去配置**链接，直接打开旁路模型页。

| 显示的原因 | 含义和处理 |
| --- | --- |
| 还没有语音账户 | 按上文添加语音账户。 |
| 语音账户的密钥缺失 | 凭据缺失或已被删除，在账户上重新选一个。 |
| 有多个语音账户，请在设置里选一个 | 在 设置 → 语音 → 语音账户 里选一个。 |
| 语音账户没有识别（朗读）模型 | 账户里没有这个按钮要用的模型。话筒需要识别模型，朗读需要朗读模型，声波按钮两个都要。把空着的那一栏补上。 |
| 话筒只在 localhost 或 https 页面可用 | 见上面的限制。 |
| 另一个标签页正在语音对话 | 先在那个标签页里退出语音对话。 |
| 语音暂时不可用，请检查连接 | 状态检查没能连上后端。检查连接，持续出现就刷新页面。 |

其他情况：

- **没有任何语音按钮**：设置 → 语音里关闭了语音输入或朗读，或后端版本早于语音功能。声波按钮要求两项功能都开着；话筒要求语音输入开着；朗读按钮要求朗读开着。
- **“话筒权限被拒绝”**：在浏览器的网站设置里允许此页面使用话筒。
- **回复没有自动朗读**：自动朗读需要设置打开、朗读模型可用，并且在你看着那个会话时有一轮结束。别的标签页正在语音对话或你正在录音时，也不会自动朗读。
- **“点击播放”**：浏览器拦截了不是由点击发起的播放，点一下按钮即可。
- **“语音出错了，请再试一次”**：服务商拒绝了调用或调用失败。在账户上测试连接，检查密钥和模型 ID，然后重试。

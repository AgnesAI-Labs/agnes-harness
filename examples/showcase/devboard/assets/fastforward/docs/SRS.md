# 车门健康监测看板 软件需求规格说明书

> 虚构企业与模拟数据，仅用于 DevBoard 演示。

## 1 客户条款（CUS）

| 编号 | 条款 | 应答 |
|---|---|---|
| CUS-001 | 按线路、车辆、车门三级展示车门健康评分 | 满足 |
| CUS-002 | 列出最需要关注的车门，按严重程度排序 | 满足 |
| CUS-003 | 数据为模拟 PHM 信号，页面须声明 | 满足 |
| CUS-004 | 对外只提供只读 HTTP 接口，非法输入须拒绝 | 满足 |

## 2 系统需求（SYS）

| 编号 | 需求 | 来源 |
|---|---|---|
| SYS-001 | 每扇门有一个 0 至 100 的健康评分和三档等级 | CUS-001 |
| SYS-002 | 页面支持线路、车辆、车门三级钻取 | CUS-001 |
| SYS-003 | 预警排行按评分从低到高列出前 N 扇门 | CUS-002 |
| SYS-004 | 信号由程序生成且可复现；接口只读并校验参数 | CUS-003、CUS-004 |

## 3 软件需求（SWR）

| 编号 | 需求 | 来源 |
|---|---|---|
| SWR-001 | 评分 = 100 减去五类信号（滑道、阻力、缓冲头磨损、关门时间、电机电流峰值）的加权扣分，权重 0.25 / 0.25 / 0.20 / 0.15 / 0.15；信号超出 0 至 1 时按边界处理 | SYS-001 |
| SWR-002 | 评分不低于 80 为「健康」，不低于 60 为「关注」，低于 60 为「告警」；信号值不低于 0.8 记为预警信号 | SYS-001 |
| SWR-003 | 页面先列线路，点线路列车辆，点车辆列车门；快速切换时只显示最后一次选择的结果 | SYS-002 |
| SWR-004 | 排行按评分升序，评分相同按车门编号；条数 1 至 50，默认 10 | SYS-003 |
| SWR-005 | 同一个种子生成同一批信号；覆盖 2 条线路共 7 列车、56 扇门 | SYS-004 |
| SWR-006 | 只接受 GET；线路、车辆不存在或 limit 不是 1 至 50 的整数时返回 400 | SYS-004 |

## 4 非功能约束

无外部依赖，不访问外网；服务由 Host 交接的监听器提供，普通部署用 `--port` 指定端口；页面显著位置声明数据为模拟。

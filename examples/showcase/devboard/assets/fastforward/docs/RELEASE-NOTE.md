# 车门健康监测看板 发布说明

> 虚构企业与模拟数据，仅用于 DevBoard 演示。

## 1 版本

| 项 | 内容 |
|---|---|
| 产品 | 车门健康监测看板 |
| 版本 | V1.0 |
| 适用 | 运维事业部内部演示，数据为模拟信号 |

## 2 功能

1. 健康评分与三档等级（SWR-001、SWR-002）；
2. 线路 → 车辆 → 车门三级钻取（SWR-003）；
3. 预警排行（SWR-004）；
4. 可复现的模拟信号，56 扇门（SWR-005）；
5. 只读接口与参数校验（SWR-006）。

## 3 启动与停止

| 项 | 内容 |
|---|---|
| 目录 | `devboard-projects/<项目编号>/` |
| 命令 | `node server.js`（Host 交接监听器）；普通部署 `node server.js --port 5180` |
| 地址 | 以命令输出的 `AGH_LOOPBACK_URL` 为准 |
| 停止 | 停止后台 job；监听只在启动它的那次运行期间有效 |

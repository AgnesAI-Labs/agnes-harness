## 1 项目概述

服务事业部承担门系统维保业务，现有 V1.0 平台只做故障记录查询。V2.0 目标是从「事后维修」转向「状态修」：汇聚多条线路门控器故障码与运行数据，计算健康评分，自动生成并闭环维保工单。

| 项 | 内容 |
|---|---|
| 类型 | 企业软件（非车载、非安全相关） |
| 用户 | 服务事业部维保工程师、服务经理；试点线路运营方维修人员 |
| 规模 | 首期接入 2000 扇门 |
| 技术路线 | 微服务、关系数据库 + 时序数据库、消息队列、Web 前端 |

## 4 质量要求

1. 评审门：编制人不得批准，评审意见全部关闭方可通过；
2. 单元测试语句覆盖率 ≥ 80%；
3. 信息安全按网络安全等级保护 2.0 第二级设计与自测；
4. 发布准则：A、B 类缺陷清零，C 类关闭或延期经评审。

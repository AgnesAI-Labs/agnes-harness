## 1 项目概述

服务事业部承担门系统维保业务，现有 V1.0 平台只做故障记录查询。V2.0 目标是从「故障修」转向「状态修」：对接门控器的 PHM 信号（滑道异常、阻力异常、缓冲头磨损、障碍物、锁闭开关、通信），汇聚多条线路门控器故障码与运行数据，计算健康评分，预警自动推送服务人员，并自动生成、闭环维保工单。

| 项 | 内容 |
|---|---|
| 类型 | 企业软件（非车载、非安全相关） |
| 用户 | 服务事业部维保工程师、服务经理；试点线路运营方维修人员 |
| 规模 | 首期接入 2000 扇门（项目技术规格书假设） |
| PHM 信号 | SLIDE 滑道异常、RESISTANCE 阻力异常、BUFFER_WEAR 缓冲头磨损、OBSTACLE 障碍物、LOCK_SWITCH 锁闭开关、COMM 通信 |
| 技术路线 | 微服务、关系数据库 + 时序数据库、消息队列、Web 前端 |

## 3 新增功能

1. 门控器故障记录汇聚与故障码标准化（SWR-501、SWR-502）；
2. 线路→车辆→车门三级健康评分与故障排行（SWR-505、SWR-507）；
3. 评分权重按线路配置，含电机电流特征（SWR-506，CR-2025-063）；
4. 自动生成维保工单与工单闭环（SWR-508、SWR-509）；
5. EAM 工单同步（SWR-512）；
6. 对接门控器 PHM 信号（滑道异常、阻力异常、缓冲头磨损、障碍物、锁闭开关、通信），预警自动推送服务人员。

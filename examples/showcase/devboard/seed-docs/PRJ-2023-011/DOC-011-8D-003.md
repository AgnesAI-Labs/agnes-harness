## D3 临时措施

1. 预警门缩短点检周期至每月，现场用库存 B 版缓冲头临时更换；
2. 加强同批次其余车辆的预警监控，磨损指标每周汇总；
3. 备件库存 B 版缓冲头标记待处理，暂停发放。

## D4 根本原因

对更换下来的缓冲头做磨损断面检查，并与库存件做对照试验：

- B 版聚氨酯配方耐磨添加剂比例偏低，在高频关门冲击与隧道粉尘工况下磨损速率约为设计假设的 2.3 倍（项目技术规格书假设）；
- 预警集中在同一批次，是该批次原料硬度偏软，磨损更快；
- 设计阶段以实验室磨损试验取值，未覆盖线路粉尘与冲击频次，来料检验也未做耐磨抽检。

根本原因记录于 CR-2026-012 的失效原因分析。

## D5 永久纠正措施

1. 缓冲头材料改为 C 版耐磨聚氨酯（物料号 NC-DR-1218，图号 NCDW-1218-00，B → C）；
2. 发起变更 CR-2026-012，CCB 批准后生成 ECN-2026-012（DOC-011-ECN-012），设计态基线升版为 CB-PRJ-2023-011-AS_DESIGNED-03；
3. 全列 1920 扇门更换缓冲头，质保期内免费，分批在库内定检窗口进行。

## D6 措施验证

- 例行试验 RT-2026-021：C 版与 B 版缓冲头加速磨损对比，C 版磨损率为 B 版的 0.41 倍，目标不大于 0.5 倍（项目技术规格书假设），合格；
- 整改进度 1920/1920，完成后维护态基线 CB-PRJ-2023-011-AS_MAINTAINED-02 与设计态基线 03 一致；
- 整改完成后 30 日内同批次无缓冲头磨损预警。

## D7 预防再发

1. 来料检验增加缓冲头硬度与耐磨对比抽检；
2. 同类缓冲头设计检查表增加线路粉尘与冲击频次的校核；
3. 新造项目的缓冲头设计（如 DES-013）按 C 版设计；PRJ-2025-042 的缓冲头寿命不得低于 C 版水平。

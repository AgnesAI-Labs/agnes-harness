## 1 引言

### 1.1 目的

本说明书规定宁川地铁 9 号线客室侧门系统的整门需求，覆盖机械（门扇、导向、缓冲、锁闭、密封）、电气（供电、驱动、安全回路、EMC）和软件（门控逻辑、通信、诊断）三个专业，是系统设计、型式试验与验收的依据。客户条款与技术协议应答见 3.1 节及 DOC-042-TA-RESP。

### 1.2 范围

适用于客室侧门整门系统：门机构（图号见 DOC-042-SAD）、DCU 硬件与 DCU 应用软件 V2.3 系列。整车电路与车体门洞由整车厂负责，相关约束以接口需求形式给出。专业需求编号：软件 SWR、机械 MER、电气 EER，均属子系统需求层。

## 2 总体描述

### 2.1 系统上下文

DCU 接收 TCMS 经 MVB 下发的集控开关门指令、司机室硬线开关门指令、零速与门使能硬线信号，控制门电机，采集 S1、S2、紧急解锁、隔离开关等信号，驱动门安全回路继电器，并向 TCMS 上报门状态与故障。

### 2.2 运行环境

- 处理器：主处理器 + 安全监控协处理器（双通道）；
- 门机构：塞拉门，净开度 1400 mm，驱动为无刷直流电机 + 传动机构（见 3.4、3.5 节）；
- 运行温度：-25 ℃～+45 ℃（车内环境）；
- 供电：DC 110 V（DC 77 V～137.5 V）；
- 环境试验：淋雨、冲击振动（IEC 61373 1 类 B 级）、EMC（EN 50121-3-2）；电子设备按 EN 50155，非金属材料防火证明按 EN 45545。

### 2.3 安全完整性假设

零速联锁、门关好判定与安全回路、障碍物检测、紧急解锁处理、防拖拽检测为安全相关功能，按 SIL2 开发（假设；客户对 CUS-011 的最终要求待确认）。锁闭装置（MER-006）、紧急解锁装置（MER-007）与门安全回路硬线（EER-004）为对应的机电安全相关项。安全功能失效时应导向安全状态：不开门、不输出门关好。

### 3.3 软件需求（SWR）

#### 3.3.1 SWR-001 开门指令处理

- 需求：MVB 集控开门与硬线开门指令取“或”，且须零速有效、门使能有效方可执行。
- 来源：SYS-001、SYS-005
- 安全相关：否
- 验证方法：测试

#### 3.3.2 SWR-002 关门指令处理

- 需求：执行关门指令；关门过程中收到开门指令应在 200 ms 内反向开门。
- 来源：SYS-002
- 安全相关：否
- 验证方法：测试

#### 3.3.3 SWR-003 电机速度闭环

- 需求：电机速度闭环控制周期 1 ms，稳态跟随误差不大于 5%。
- 来源：SYS-003
- 安全相关：否
- 验证方法：测试

#### 3.3.4 SWR-004 开关门曲线参数

- 需求：开门 3.0 s、关门 3.5 s 为默认值，参数可在 ±0.5 s 范围内调整并做范围校验。
- 来源：SYS-003
- 安全相关：否
- 验证方法：测试

#### 3.3.5 SWR-005 零速双通道采集

- 需求：零速信号双通道采集并逐周期比较，不一致持续 50 ms 判零速无效。
- 来源：SYS-004
- 安全相关：是
- 验证方法：测试 + 分析

#### 3.3.6 SWR-006 零速无效屏蔽开门

- 需求：零速无效时屏蔽全部开门输出，包括维护模式下的本地开门。
- 来源：SYS-004、SYS-018
- 安全相关：是
- 验证方法：测试 + 分析

#### 3.3.7 SWR-007 门使能侧判别

- 需求：按左/右门使能信号判别允许开门侧，非使能侧开门指令丢弃并记录。
- 来源：SYS-005
- 安全相关：是
- 验证方法：测试 + 分析

#### 3.3.8 SWR-008 障碍物检测

- 需求：关门行程中电流超自适应阈值或速度偏差超限判为障碍物，检出后 200 ms 内反向。
- 来源：SYS-006
- 安全相关：是
- 验证方法：测试 + 分析

#### 3.3.9 SWR-009 重开计数与报警

- 需求：连续重开计数，第 3 次后门保持开启并置 MVB 报警位。
- 来源：SYS-007
- 安全相关：否
- 验证方法：测试

#### 3.3.10 SWR-010 最终关闭区力限制

- 需求：关门行程最后 30 mm 不反向，改为限制电机电流使夹紧力不大于 150 N。
- 来源：SYS-006
- 安全相关：是
- 验证方法：测试 + 分析

#### 3.3.11 SWR-011 S1/S2 信号校验

- 需求：采集 S1、S2 信号并做合理性校验，不一致超过 300 ms 报门开关故障。
- 来源：SYS-008
- 安全相关：是
- 验证方法：测试 + 分析

#### 3.3.12 SWR-012 门关好判定与安全回路

- 需求：S1、S2 均有效且电机静止时判门关好锁闭，驱动安全回路继电器。

- 验证方法：测试 + 分析

## 4 接口需求

### 4.1 MVB 过程数据

| 端口 | 方向 | 周期 | 内容 |
|---|---|---|---|
| 0x2A0 | TCMS → DCU | 64 ms | 集控开/关门指令、门使能镜像、时间同步 |
| 0x2A4 | DCU → TCMS | 64 ms | 门状态字（开到位、关到位、锁闭、隔离、紧急解锁） |
| 0x2A6 | DCU → TCMS | 64 ms | 故障与报警字（障碍物报警、通信故障、门开关故障） |
| 0x2A8 | DCU → TCMS | 512 ms | 诊断数据：开关门次数、软件版本、参数校验和 |

### 4.2 硬线接口

| 信号 | 方向 | 说明 |
|---|---|---|
| 零速（双通道） | 输入 | SWR-005 |
| 左/右门使能 | 输入 | SWR-007 |
| 硬线开/关门 | 输入 | SWR-001、SWR-002 |
| S1、S2 | 输入 | SWR-011 |
| 紧急解锁、隔离 | 输入 | SWR-013、SWR-014 |
| 安全回路继电器 | 输出 | SWR-012 |
| 门安全回路硬线、S1/S2 开关 | 输入/输出 | EER-004 |
| 零速与使能硬线输入电路（滤波、隔离） | 输入 | EER-007 |

### 4.3 机械与电源接口

| 接口 | 对方 | 约束 |
|---|---|---|
| 车体门洞 | 华东某车辆厂 | 门楣处净高 1850 mm，净开度 1400 mm，门洞上沿与安装孔位以整车接口图为准（MER-001） |
| 门槛与排水 | 华东某车辆厂 | 门页下缘与门槛间隙及排水通道符合接口图（MER-004） |
| 供电 | 整车低压配电 | DC 110 V，DC 77 V～137.5 V，每门独立保护（EER-001，项目技术规格书假设） |
| 接地与屏蔽 | 整车线束 | 保护接地连续，屏蔽层单端接地（EER-005、EER-006） |

## 5 非功能需求

1. 实时性：主控制周期 1 ms，安全比较周期 10 ms，MVB 周期 64 ms；
2. 资源：CPU 负载峰值不大于 70%，Flash、RAM 余量不小于 30%；
3. 编码：C 语言，遵循 MISRA C:2012；
4. 可维护性：参数与软件版本分区存储，可在车升级。

## 6 评审结论

DL1 设计联络（一）结论：通过（项目经理与客户代表会签）。评审意见 3 条，已在 V1.0 关闭：

1. SWR-010 最终关闭区的行程范围未量化 → 明确为关门行程最后 30 mm；
2. SWR-016 通信超时周期 → 与华东某车辆厂确认为 3 个周期（192 ms）；
3. CUS-001 净高 1860 mm 与车体门洞上沿不符 → 客户书面确认按 1850 mm 供货（MER-001，见 DOC-042-TA-RESP）。

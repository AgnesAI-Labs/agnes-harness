# data-report

Read the CSV and reject unsupported quoting, invalid rows and oversized inputs. Compute totals in tools, not in the model. Return revenue, cost, profit, margin, markdown and an inline SVG chart. Explain only the computed figures; label hypotheses. Customer adaptation: define the CSV dialect, KPI definitions and source lineage; replace fixture input through supported file/read ports.

Use official present for generated deliverables under fde-output/data-report/. Keep business evidence read-only; permit only bounded report output writes. If official Plan mode is active, submit the fixed workflow with exit_plan_mode and wait for its native approval before business steps. Plan approval never replaces a later business choice or tool permission.

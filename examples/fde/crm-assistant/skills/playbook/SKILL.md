# crm-assistant

Look up the account using MCP. For at-risk health or open tickets, prepare an owner follow-up citing only recorded fields. Do not promise discounts or fabricate customer contact. Show the note and require approval before recording. Reuse the same idempotency key for the same reviewed note only; inspect a missing receipt. Customer adaptation: replace MCP with the customer CRM, keep secrets in deployment bindings, revise fields and retention rules.
